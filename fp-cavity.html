法布里-珀罗腔结构与基本原理
原理

法布里-珀罗腔（Fabry-Pérot cavity）由两块平行的反射镜构成。光在两镜面之间多次往返反射，形成多光束干涉，从而产生尖锐的谐振峰。F-P 腔是激光器、滤波器、光谱分析等系统的核心组件。

图 1. F-P 腔结构示意图：入射光 $E_0$ 经 $M_1$ 透射进入腔内，多次往返后经 $M_2$ 透射输出

多光束干涉：入射光 $E_0$ 从左侧射入 $M_1$，每次往返在腔内积累相位 $\delta$。各次透射光场构成等比数列，求和后得到总透射场和反射场。

谐振条件：当往返相位 $\delta = 2m\pi$（$m$ 为整数）时，透射率取极大值，腔发生谐振。相邻纵模频率间隔称为自由光谱范围（FSR）。

精细度（Finesse）：反映谐振峰的尖锐程度，由镜面反射率决定，是 F-P 腔品质的核心指标。

图 2. F-P 腔透射谱：等间隔谐振峰，FSR 为纵模间隔，FWHM 为单峰线宽
多光束干涉场推导
推导

Step 1：单次往返的光场变化 — 入射光 $E_0$ 经 $M_1$ 透射进入腔内，振幅为 $E_0 t_1$。在腔内传播半程获得相位 $\delta/2$，到达 $M_2$ 后部分透射出腔（$\times t_2$），部分反射回腔（$\times r_2$）。往返总相位为 $\delta = \frac{4\pi n L \nu}{c}$。

Step 2：透射光场求和 — 腔内光每次到达 $M_2$ 后透射出去的光场依次为：

$$E_{t,1} = E_0\, t_1 t_2\, e^{i\delta/2}, \quad E_{t,2} = E_{t,1} \cdot r_1 r_2\, e^{i\delta}, \quad E_{t,3} = E_{t,1} \cdot (r_1 r_2\, e^{i\delta})^2$$

总透射场为等比级数求和：

$$E_t = E_0\, t_1 t_2\, e^{i\delta/2} \sum_{m=0}^{\infty} (r_1 r_2\, e^{i\delta})^m = \frac{E_0\, t_1 t_2\, e^{i\delta/2}}{1 - r_1 r_2\, e^{i\delta}}$$
总透射光场（等比级数求和）

Step 3：反射光场（含镜面损耗） — 反射光由 $M_1$ 直接反射（$r_1 E_0$）和腔内经 $M_1$ 漏出的多光束叠加而成，考虑反射相移关系 $t_1 t_1' = -T_1$（功率反射率 $R_i = |r_i|^2$、透射率 $T_i = |t_i|^2$、损耗 $L_i = 1 - R_i - T_i$）：

$$E_r = E_0 \left[r_1 - \frac{T_1 r_2 e^{i\delta}}{1 - r_1 r_2 e^{i\delta}}\right], \qquad R_{\text{cav}}(\nu) = \left|\frac{E_r}{E_0}\right|^2 = \left|\frac{r_1(1 - r_1 r_2 e^{i\delta}) - T_1 r_2 e^{i\delta}}{1 - r_1 r_2 e^{i\delta}}\right|^2$$
含镜面损耗的腔反射场与反射率

Step 4：Airy 函数 — 取透射率 $T = |E_t/E_0|^2$，令有效振幅反射率乘积 $R = |r_1 r_2| = \sqrt{R_1 R_2}$，Airy 精细度系数为 $F = \frac{4R}{(1-R)^2}$：

$$T(\nu) = \frac{|t_1 t_2|^2}{|1 - r_1 r_2\, e^{i\delta}|^2} = \frac{T_{\max}}{1 + F\sin^2(\delta/2)}, \qquad T_{\max} = \frac{T_1 T_2}{(1 - \sqrt{R_1 R_2})^2}$$
Airy 透射函数（对称无损耗镜面时 $T_{\max} = 1$）
$$R(\nu) = 1 - T(\nu) = \frac{F\sin^2(\delta/2)}{1 + F\sin^2(\delta/2)}$$
反射率（对称无损耗条件）
关键参数公式
参数
$$\Delta\nu_{\text{FSR}} = \frac{c}{2nL}$$
自由光谱范围（FSR）
$$\mathcal{F} = \frac{\pi\sqrt{R}}{1-R}$$
精细度（Finesse），$R = |r_1 r_2| = \sqrt{R_1 R_2}$
$$\Delta\nu_{\text{FWHM}} = \frac{\Delta\nu_{\text{FSR}}}{\mathcal{F}} = \frac{c}{2nL\mathcal{F}}$$
谐振峰半高全宽（FWHM）
$$Q = \frac{\nu_0}{\Delta\nu_{\text{FWHM}}} = \frac{2nL\mathcal{F}\nu_0}{c}$$
品质因子（Q factor）

考虑镜面损耗时（$R_i + T_i + L_i = 1$），能量守恒关系为 $T(\nu) + R_{\text{cav}}(\nu) + \Lambda(\nu) = 1$。

仿真算法：高精细度谐振峰自适应采样
数值算法

当 $R_1, R_2 \to 0.999$ 时，$\mathcal{F} > 3000$，谐振峰极窄。若在 $3\,\text{FSR}$ 范围内仅做等间距采样，离散网格极易跨过峰顶导致峰值失真。仿真器构建基础均匀网格 + 谐振峰二次加密网格：

$$\nu_k \in \left\{\nu_{\text{uniform}}\right\} \cup \bigcup_{m=-1}^{1} \left\{m\,\Delta\nu_{\text{FSR}} + \operatorname{sgn}(u_j)\, u_j^2 \cdot \min(0.45\,\Delta\nu_{\text{FSR}},\, 4\,\Delta\nu_{\text{FWHM}})\right\}$$
排序后在每个谐振峰附近自动加密，确保任意高 Q 峰值无截断渲染
