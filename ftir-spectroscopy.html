8光场自干涉与傅里叶变换光谱仪（FTIR）

光场表征需求 → 迈克尔逊自干涉与平方律探测 → 维纳-辛钦定理光谱反演 → 相干与非相干光源统一框架 → 切趾窗与四区联动仿真器

光场表征的需求：从时域到频域
原理

光场的完整表征需要同时获取其时域结构（电场随时间的演化 $E(t)$）和频域结构（功率谱密度 $S(f) = |\tilde{E}(f)|^2$）。两者通过傅里叶变换相互联系：

$$\tilde{E}(f) = \int_{-\infty}^{+\infty} E(t)\,e^{-i 2\pi f t}\,\mathrm{d}t \quad \Longleftrightarrow \quad S(f) = |\tilde{E}(f)|^2$$

然而，光载波频率高达数百太赫兹（$10^{14}$ Hz 量级），没有任何电子探测器或示波器能直接记录光场的瞬时振荡。光电探测器只能响应光强的时间积分（平方律探测），输出的是包络功率信号而非完整电场。因此，如何在不直接测量光场振荡的前提下获取其频谱信息，是光谱测量的核心物理挑战。

自干涉机制：用延时作为探针
原理

迈克尔逊干涉仪将入射光经分束镜分为两路，其中一路引入可调延时 $\tau$（通过动镜位移实现），重新合束后送入光电探测器。干涉图 $I(\tau)$ 的交流分量恰好是光场电场的自相关函数 $R_{EE}(\tau)$ 的两倍。根据维纳-辛钦定理，去直流后执行傅里叶变换即可无损还原功率谱密度：

$$I_{\text{AC}}(\tau) = 2\,R_{EE}(\tau) \quad \Longrightarrow \quad S_{\text{FTIR}}(f) = \tfrac{1}{2}\,\text{Re}\!\left\{\mathcal{F}\{I_{\text{AC}}(\tau)\}\right\} = S_{\text{true}}(f)$$

傅里叶变换光谱仪（FTIR）核心优势
原理

FTIR 由宽带光源、迈克尔逊干涉仪、光电探测器与信号反演单元构成。相比传统色散型光谱仪，FTIR 具有 Fellgett 优势（多通道同时探测，信噪比更高）和 Jacquinot 优势（圆形光阑通光量大），在中红外光谱分析领域占据主导地位。

相干光源与非相干光源的统一描述
原理

相干脉冲光源的干涉图交流分量是脉冲电场的确定性自相关函数；非相干连续光源（黑体、自发辐射）在 $|\tau| \lesssim \tau_c$ 内仍保持相位相关，在 $\tau=0$ 附近形成尖锐的中心爆峰（Central Burst），增大积分平均次数 $M$ 可将散斑信噪比按 $\sqrt{M}$ 提升并严格收敛至理论功率谱。

有限扫描截断与分辨率极限
原理

动镜有限行程等价于乘以切趾窗 $W(\tau)$，导致频域卷积 $S_{\text{FTIR}}(f) = S_{\text{true}}(f) * \tilde{W}(f)$。理论分辨率极限由最大扫描延时决定：

$$\Delta f \approx \frac{1}{2\tau_{\max}} = \frac{c}{2\,\text{OPD}_{\max}} \quad \Rightarrow \quad \Delta\tilde{\nu} \approx \frac{1}{2\,\text{OPD}_{\max}}$$
一、相干脉冲光源的时域表示与真实功率谱密度
公式

设入射到迈克尔逊干涉仪的实值脉冲光电场为慢变包络 $A(t)$ 与光载波的乘积：$E(t) = A(t)\cos(2\pi f_0 t)$。

脉冲形态包络表达式 $A(t)$频谱特征
高斯脉冲$\exp\!\left[-2\ln 2 \cdot \left(\dfrac{t}{\tau_p}\right)^2\right]$频谱仍为高斯型，无旁瓣
双曲正割$\operatorname{sech}\!\left(1.7627\,\dfrac{t}{\tau_p}\right)$孤子脉冲典型形态，频谱呈 $\operatorname{sech}^2$ 衰减
洛伦兹型$\dfrac{1}{1 + (2t/\tau_p)^2}$频谱呈指数衰减
矩形脉冲$\operatorname{rect}\!\left(\dfrac{t}{\tau_p}\right)$频谱为 $\operatorname{sinc}^2$ 函数，带显著旁瓣
双色高斯脉冲$\tfrac{1}{2}A_{\text{gauss}}(t)\big[\cos(2\pi f_1 t)+\cos(2\pi f_2 t)\big]$双峰频谱，用于检验分辨率极限
$$\tilde{E}(f) = \mathcal{F}\{E(t)\} = \int_{-\infty}^{+\infty} E(t)\,e^{-i 2\pi f t}\,\mathrm{d}t, \qquad S_{\text{true}}(f) = |\tilde{E}(f)|^2$$
二、迈克尔逊干涉仪的延时叠加与光电探测积分
公式

脉冲光经 50:50 分束镜分为两束：定镜臂 $E_1(t) = \tfrac{1}{2}E(t)$ 与动镜臂 $E_2(t;\tau) = \tfrac{1}{2}E(t-\tau)$（$\tau = \frac{2\Delta x}{c}$）。将常数系数 $\frac{1}{4}$ 吸收至探测器光强归一化中，合束总电场为 $E_{\text{total}}(t;\tau) = E(t) + E(t-\tau)$，平方律时间积分输出干涉图：

$$I(\tau) = \int_{-\infty}^{+\infty} \big|E(t) + E(t - \tau)\big|^2\,\mathrm{d}t = 2\int |E(t)|^2\,\mathrm{d}t + 2\int E(t)E(t - \tau)\,\mathrm{d}t$$
$$I(\tau) = I_{\text{DC}} + I_{\text{AC}}(\tau), \quad I_{\text{DC}} = 2\int |E(t)|^2\,\mathrm{d}t, \quad I_{\text{AC}}(\tau) = 2\int E(t)E(t-\tau)\,\mathrm{d}t = 2\,R_{EE}(\tau)$$

在零光程差处（ZPD, $\tau = 0$），相长干涉达到极大值 $I(0) = 2\,I_{\text{DC}}$。

三、去直流与傅里叶变换光谱反演（自相关定理）
公式

对去直流后的 $I_{\text{AC}}(\tau) = I(\tau) - I_{\text{DC}}$ 执行傅里叶变换，交换积分次序并作变量替换 $u = t - \tau$：

$$\mathcal{F}\{I_{\text{AC}}(\tau)\} = 2\int E(t)\,e^{-i 2\pi f t}\,\mathrm{d}t \int E(u)\,e^{+i 2\pi f u}\,\mathrm{d}u = 2\,\tilde{E}(f)\,\tilde{E}^*(f) = 2\,|\tilde{E}(f)|^2$$

由偶对称性 $I_{\text{AC}}(-\tau) = I_{\text{AC}}(\tau)$，其傅里叶变换为纯实数（余弦变换），严格证明：

$$S_{\text{FTIR}}(f) = \frac{1}{2}\operatorname{Re}\!\big\{\mathcal{F}\{I_{\text{AC}}(\tau)\}\big\} = \int_{0}^{+\infty} I_{\text{AC}}(\tau)\cos(2\pi f \tau)\,\mathrm{d}\tau = S_{\text{true}}(f)$$
四、非相干连续光源的统计光学推导
公式

对于热光源或自发辐射光源，探测器测得系综平均干涉图 $I(\tau) = \big\langle |E(t) + E(t-\tau)|^2 \big\rangle = I_{\text{DC}}[1 + \gamma(\tau)]$，其中一阶时间自相关函数 $\Gamma(\tau) = \langle E(t)E(t-\tau)\rangle$ 满足维纳-辛钦定理：

$$\Gamma(\tau) = \int_{-\infty}^{+\infty} S(f)\,e^{i 2\pi f \tau}\,\mathrm{d}f \quad \Longleftrightarrow \quad S(f) = \int_{-\infty}^{+\infty} \Gamma(\tau)\,e^{-i 2\pi f \tau}\,\mathrm{d}\tau$$

自发辐射光源（洛伦兹线型）与黑体辐射光源（普朗克定律）：

$$S_{\text{SE}}(f) \propto \frac{1}{1 + \left[\dfrac{2(f - f_0)}{\Delta f}\right]^2}, \qquad \tau_c = \frac{1}{\pi\,\Delta f}$$
$$S_{\text{BB}}(f, T) = \frac{2 h f^3}{c^2}\frac{1}{\exp\!\left(\dfrac{h f}{k_B T}\right) - 1}, \qquad f_{\text{peak}} \approx 2.82144\,\frac{k_B T}{h} \approx 0.05879\,T\;\text{(THz)}$$

有限积分平均次数 $M$：单次短曝光（$M=1$）存在 $100\%$ 相对标准差的指数散斑涨落，对 $M$ 次独立相干片段累加平均后：

$$\overline{I_{\text{AC}}}(\tau) = \frac{1}{M}\sum_{m=1}^{M} I_{\text{AC}}^{(m)}(\tau) \quad \Longrightarrow \quad \text{SNR} \propto \sqrt{M}$$

六、仿真算法：离散 FFT 反演与随机相位场合成
数值算法
  • 确定性脉冲：在 $N=4096, \Delta t=0.5\,\text{fs}$ 网格上经循环移位与 Radix-2 FFT 计算 $S_{\text{true}}(f)$，逆 FFT 精确生成自相关干涉图 $I_{\text{AC}}(\tau)$，乘以切趾窗 $W(\tau)$ 后再次 FFT 得 $S_{\text{FTIR}}(f)$。
  • 非相干随机场：在频域用 Box-Muller 变换生成独立复高斯随机振幅，逆 FFT 合成平稳随机波形 $E(t)$；有限平均 $M$ 通过对各频点叠加 $M$ 个独立指数随机变量（Gamma 分布）模拟散斑收敛。
  • 定量评价：在显示频段内实时计算决定系数 $R^2$ 与均方根误差 $\text{RMSE}$。
