5激光-微腔自注入锁定（Self-Injection Locking）

反馈物理机制 → 归一化耦合方程 → S 曲线解析推导 → 锁定带宽与线宽窄化 → 交互式仿真器

1自注入锁定的基本概念
什么是自注入锁定？
概述

自注入锁定（Self-Injection Locking, SIL）是一种利用外部高 $Q$ 光学微腔对半导体激光器进行频率稳定和线宽窄化的技术。与传统的外部注入锁定（使用独立的主激光器注入从激光器）不同，SIL 中的反馈光来自激光器自身——激光输出经总线波导耦入微腔，微腔存储并回散射的光场返回激光腔形成自洽反馈，无需额外的主激光器。

这一技术的核心优势在于：

  • 线宽大幅压缩：理论上可将 Schawlow-Townes 本征线宽压缩 $\sim 1/S^2$ 倍，实现 Hz 级线宽。
  • 频率锁定到微腔谐振：激光频率被“钉扎”在微腔高 $Q$ 谐振频率附近，长期频率稳定性由微腔材料决定。
  • 结构紧凑：激光二极管与微环腔通过总线波导耦合，适合光子集成电路（PIC）集成。
  • 无需独立泵浦源：反馈光来自激光自身，系统功耗和复杂度显著降低。
2物理机制与反馈路径
反馈来源与频率选择性
物理图像

反馈来源：激光器输出光通过总线波导耦入外部高 $Q$ 环形微腔。接近谐振频率 $\omega_c$ 的光场被微腔捕获存储，存储的光场通过耦合区反馈回总线波导，返回激光腔内。

频率选择性：微腔的窄谐振（线宽 $\kappa = \omega_c/Q$）提供了反馈的频率选择性——只有在谐振附近的频率分量获得强反馈，从而将激光频率“拉”向微腔谐振频率。

图 1. 激光二极管-总线波导-微环腔耦合系统结构示意：CW 模式由激光耦入，瑞利背散射产生 CCW 模式返回激光腔
3关键物理现象
瑞利背散射与模式分裂
模式耦合

微腔中的瑞利背散射（耦合率 $\beta = 2\gamma/\kappa$）将 CW 模式能量转移到 CCW 模式，CCW 场经延迟返回激光腔形成反馈。当 $\beta > 0$ 时，原本简并的 CW/CCW 模式发生分裂，传输谱出现双谷结构。

S 曲线与锁定平台
调谐特性

$\xi$-$\zeta$ 曲线描述了自由运行激光频率 $\omega_0$（横轴 $\xi$）与锁定后实际发射频率 $\omega$（纵轴 $\zeta$）之间的关系。锁定平台上 $\zeta$ 几乎不随 $\xi$ 变化，正向扫描和反向扫描遵循不同分支并呈现滞回行为，边界由鞍结分岔决定。

线宽窄化机制
线宽压缩

锁定后激光频率噪声被稳定因子 $S = 1 + 2K\cos\psi$ 压缩，本征线宽缩小 $1/S^2$ 倍。$\psi = 0$ 时压缩最优，$\psi = \pi$ 时反馈反而增宽。

Lang-Kobayashi
$$\frac{da_L}{d\tau} = \left[(1+i\alpha_g)\, g_N (N - N_{\text{th}}) - i\xi\right] a_L + \kappa_{\text{fb}}\, e^{i\phi_0}\, b_0(\tau - \tau_s)$$
激光二极管电场方程（含光反馈延迟项）
$$\frac{dN}{d\tau} = J - \gamma_N N - G(N)|a_L|^2$$
载流子速率方程
  • $g_N$：归一化到 $\kappa/2$ 的微分光增益；$N_{\text{th}}$：孤立激光二极管阈值载流子密度。
  • $\kappa_{\text{fb}}$：微腔回馈到激光腔的无量纲反馈耦合率；$\phi_0 = \omega_c \tau_s$：外部往返延迟静态传播相位。
  • $b_0(\tau - \tau_s)$：微腔回散射的 CCW 场（延迟项）；$J, \gamma_N, G(N)$：归一化泵浦电流、载流子衰减率、饱和增益函数。

耦合 LLE

$$\frac{\partial b}{\partial \tau} = -(1+i\zeta_0)\,b + i\,d_2\frac{\partial^2 b}{\partial \theta^2} + i\left(|b|^2 + 2|a|^2\right)b + i\beta\,a$$

3SIL 调谐方程解析推导（S 曲线）
稳态锁定调谐曲线的逐步推导
解析推导

在线性 CW 单纵模区域中，忽略色散与 Kerr 频移，逐步推导稳态 S 曲线：

Step 1：稳态谐波 ansatz — 设激光与微腔锁定到共同频率 $\omega$，对应归一化失谐 $\zeta = \frac{2(\omega - \omega_c)}{\kappa}$：

$$a_L(\tau) = A_L\,e^{-i\zeta\tau}, \quad a(\tau) = A\,e^{-i\zeta\tau}, \quad b(\tau) = B\,e^{-i\zeta\tau}$$

Step 2：求解微腔代数方程 — 代入线性化单模 LLE 令 $\partial a/\partial\tau = \partial b/\partial\tau = 0$：

$$(1 - i\zeta)\,A - i\beta\,B = f, \qquad -i\beta\,A + (1 - i\zeta)\,B = 0$$

由第二式得 $A = \frac{1-i\zeta}{i\beta}B$，代入第一式得：

$$B = \frac{i\beta}{(1-i\zeta)^2 + \beta^2}\,f, \qquad A = \frac{1-i\zeta}{(1-i\zeta)^2 + \beta^2}\,f$$

Step 3：激光方程的绝热载流子消去 — 稳态下延迟 CCW 反馈场 $b(\tau-\tau_s) = B\,e^{i\zeta\tau_s}e^{-i\zeta\tau}$，代入激光方程并除以 $A_L$：

$$-i\zeta = (1+i\alpha_g)\,\Delta g - i\xi + \frac{i\beta\,\kappa_{\text{fb}}\,\eta_{\text{in}}\,e^{i\omega\tau_s}}{(1-i\zeta)^2 + \beta^2}$$

Step 4：分离实部和虚部 — 定义微腔复反射传递函数 $\chi(\zeta)$：

$$\chi(\zeta) = \frac{i\beta}{(1-i\zeta)^2 + \beta^2} = \frac{-2\beta\zeta + i\beta(1+\beta^2-\zeta^2)}{(1+\beta^2-\zeta^2)^2 + 4\zeta^2}$$

令 $\tilde{\kappa} = \kappa_{\text{fb}}\eta_{\text{in}}$，$\theta_s = \omega\tau_s$，分离实部与虚部得 $\Delta g = -\tilde{\kappa}\,\text{Re}[e^{i\theta_s}\chi(\zeta)]$ 与 $-\zeta = \alpha_g\Delta g - \xi + \tilde{\kappa}\,\text{Im}[e^{i\theta_s}\chi(\zeta)]$。

Step 5：消去 $\Delta g$ 得到解析调谐曲线 — 定义 $\psi = \omega\tau_s - \arctan(\alpha_g)$ 与 $K = 2\beta\tilde{\kappa}\sqrt{1+\alpha_g^2}$：

$$\xi(\zeta) = \zeta + K\,\frac{2\zeta\cos\psi + (1+\beta^2-\zeta^2)\sin\psi}{(1+\beta^2-\zeta^2)^2 + 4\zeta^2}$$
SIL 解析调谐 S 曲线（与 $\chi(\zeta)$ 分子符号严格一致）
4锁定带宽、线宽窄化与微腔传输谱
锁定范围与线宽压缩
锁定特性
$$\Delta\omega_{\text{lock}} \approx \frac{\kappa}{2}\,K$$
强反馈（$K \gg 1$）与最优相位（$\psi = 0$）下的近似锁定带宽

在谐振中心 $\zeta = 0$（$\beta \ll 1$）处对 S 曲线求导，得频率稳定因子与线宽压缩比：

$$S = \left.\frac{d\xi}{d\zeta}\right|_{\zeta=0,\beta\ll 1} = 1 + 2K\cos\psi, \qquad \frac{\delta\omega}{\delta\omega_0} = \left(\frac{d\zeta}{d\xi}\right)^2 = \frac{1}{(1 + 2K\cos\psi)^2}$$
稳定因子与线宽压缩比（与 S 曲线分子 $2\zeta\cos\psi$ 严格一致）
总线波导功率传输
传输谱

由输入-输出耦合理论，$s_{\text{out}} = f - 2\eta_c A$，代入稳态解 $A$ 得归一化输出功率传输：

$$T(\zeta) = \left|1 - \frac{2\eta_c(1-i\zeta)}{(1-i\zeta)^2+\beta^2}\right|^2$$
  • 远离谐振（$|\zeta| \gg 1$）：$T(\zeta) \to 1$（全传输）。
  • 锁定范围内（$\zeta \approx 0$）：$T(\zeta)$ 跌入宽平谐振吸收谷；$\beta > 0$ 时出现分裂双谷。
