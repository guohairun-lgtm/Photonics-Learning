6Kerr 耗散孤子（Dissipative Kerr Soliton）

LLE 归一化方程 → 拉格朗日密度函数 → 变分法稳态孤子解 → 分岔稳定性 → Strang 分裂 SSFM 数值验证与光频梳表征

1耗散 Kerr 孤子的基本概念
什么是耗散 Kerr 孤子？
概述

耗散 Kerr 孤子（Dissipative Kerr Soliton, DKS）是在连续波（CW）泵浦驱动的光学微腔中，由 Kerr 非线性效应与色散的平衡，以及泵浦与损耗的平衡共同维持的超短光脉冲。它是光学频率梳产生的核心物理机制之一。

与传统的保守孤子（如光纤中的基孤子）不同，DKS 存在于耗散系统中——腔内光场不断被损耗，又被外部泵浦持续补充。孤子的存在依赖于两种动态平衡：

  • 色散 ↔ 非线性平衡：群速度色散（GVD）使脉冲展宽，Kerr 自相位调制（SPM）使脉冲压缩，两者平衡维持脉冲形状。
  • 损耗 ↔ 泵浦平衡：腔内线性损耗耗散光能量，外部 CW 泵浦持续注入能量，两者平衡维持脉冲能量。

正是这种双重平衡使得 DKS 成为耗散结构的典型范例——远离热力学平衡态的开放系统中自发形成的时空有序结构。

2形成机制与相图
从调制不稳定性到孤子
物理图像
  • CW 背景：CW 泵浦光耦入微腔后，首先建立稳定的连续波背景场 $\psi_0$。
  • 调制不稳定性（MI）：当泵浦功率超过 MI 阈值，CW 态对微扰变得不稳定，自发产生周期性调制图案（Turing pattern）。
  • 亚谐振激发：进一步调节失谐 $\delta_0$（扫频进入谐振），调制图案演化为局部能量集中的脉冲结构。
  • 孤子锁定：当失谐足够大，单个或多个 sech 型孤子在 CW 背景上稳定形成——即耗散 Kerr 孤子。
图 1. DKS 形成的四个阶段：从 CW 背景到调制不稳定性、多脉冲态、最终锁定为单孤子
色散区域的符号约束
色散
  • 反常色散（$d_2 > 0$）：要求 $\delta_0 > 0$（与 $d_2$ 同号），产生亮孤子——脉冲峰值高于 CW 背景，呈 sech 型包络。
  • 正常色散（$d_2 < 0$）：要求 $\delta_0 < 0$，产生暗孤子——脉冲为 CW 背景上的凹陷，呈 tanh 型包络。

这一符号约束源于变分解析解 $A = \sqrt{2\delta_0}$ 和 $W = \sqrt{d_2/(2\delta_0)}$ 均需实数，即 $\delta_0$ 与 $d_2$ 必须同号。

3关键物理现象
光频梳（Optical Frequency Comb）
频梳

DKS 在频域表现为等间距的梳状谱线，模式间隔等于微腔自由光谱范围（FSR），广泛应用于精密计量、分子光谱学、WDM 光通信与天文定标。

呼吸子与混沌
动力学

当泵浦 $S$ 增大或失谐 $\delta_0$ 减小时，稳态孤子通过 Hopf 分岔失稳，演化为呼吸子（Breather）——脉冲振幅与脉宽以频率 $\omega_H$ 周期性振荡；进一步失稳则进入混沌态。

Cherenkov 辐射与色散波
辐射

当三阶色散（TOD, $d_3$）不为零时，孤子辐射色散波（Cherenkov radiation），在频域表现为孤子谱包络之外的尖峰，同时引起孤子在方位角空间中的群速度漂移。

1归一化 Lugiato-Lefever 方程
标准归一化 LLE
LLE

在光学微腔中，描述慢变包络光场 $\psi(\theta, t)$ 演化的无量纲 LLE 为：

$$i \frac{\partial \psi}{\partial t} + \frac{d_2}{2} \frac{\partial^2 \psi}{\partial \theta^2} + i\frac{d_3}{6}\frac{\partial^3 \psi}{\partial \theta^3} + |\psi|^2 \psi - \delta_0 \psi = -i \psi + i S$$
归一化 LLE（含三阶色散 $d_3$）
  • $t$：慢时间（归一化至光子寿命），$\theta \in [-\pi, \pi]$：微腔方位角（快时间）。
  • $d_2$：群速度色散系数（$d_2 > 0$ 为反常色散，支持亮孤子）；$d_3$：三阶色散。
  • $\delta_0$：频率失谐量（反常色散要求 $\delta_0 > 0$）；$S$：外部 CW 泵浦振幅。
  • 方程结构：左侧为保守演化部分；右侧 $-i\psi$ 为腔内线性损耗，$iS$ 为外部泵浦驱动。
2拉格朗日密度函数与变分原理
保守内核与拉格朗日密度 $\mathcal{L}_0$
变分法

核心思路：剥离右侧非保守项（损耗 $-i\psi$、驱动 $iS$），系统退化为带失谐的 NLSE。通过逆变分积分构造作用量泛函 $\mathcal{A} = \iint \mathcal{L}_0 \, d\theta \, dt$：

$$i \frac{\partial \psi}{\partial t} + \frac{d_2}{2} \frac{\partial^2 \psi}{\partial \theta^2} + |\psi|^2 \psi - \delta_0 \psi = 0$$

拉格朗日密度函数：

$$\mathcal{L}_0 = \frac{i}{2} \left( \psi^* \frac{\partial \psi}{\partial t} - \psi \frac{\partial \psi^*}{\partial t} \right) - \frac{d_2}{2} \left| \frac{\partial \psi}{\partial \theta} \right|^2 + \frac{1}{2} |\psi|^4 - \delta_0 |\psi|^2$$
动能项 · 色散梯度能量 · Kerr 非线性势能 · 失谐势阱

带阻尼的欧拉-拉格朗日方程（非保守广义力 $\mathcal{R} = -i\psi + iS$）：

$$\frac{\partial \mathcal{L}_0}{\partial \psi^*} - \frac{\partial}{\partial t}\left( \frac{\partial \mathcal{L}_0}{\partial \psi^*_t} \right) - \frac{\partial}{\partial \theta}\left( \frac{\partial \mathcal{L}_0}{\partial \psi^*_\theta} \right) = \mathcal{R}$$

偏导验证：

  • $\frac{\partial \mathcal{L}_0}{\partial \psi^*} = \frac{i}{2} \psi_t + |\psi|^2 \psi - \delta_0 \psi$
  • $-\frac{\partial}{\partial t}\left( \frac{\partial \mathcal{L}_0}{\partial \psi^*_t} \right) = \frac{i}{2} \psi_t$
  • $-\frac{\partial}{\partial \theta}\left( \frac{\partial \mathcal{L}_0}{\partial \psi^*_\theta} \right) = \frac{d_2}{2} \psi_{\theta\theta}$

三项相加得 $i \psi_t + \frac{d_2}{2}\psi_{\theta\theta} + |\psi|^2\psi - \delta_0 \psi$，令其等于 $\mathcal{R} = -i\psi + iS$，严格重构出完整 LLE。

3集体坐标变分法求解稳态孤子
sech 试探解与约化拉格朗日量
Ansatz

试探解（Ansatz）：设反常色散区（$d_2 > 0$）光场由弱连续波背景 $\psi_0$ 与双曲正割孤子脉冲叠加：

$$\psi(\theta, t) = \psi_0 + A(t)\, \operatorname{sech}\left(\frac{\theta - \theta_0(t)}{W(t)}\right) e^{i\phi(t)}$$
CW 背景 + sech 孤子脉冲叠加

CW 背景解（高失谐线性近似）：

$$\psi_0 \approx \frac{iS}{-\delta_0 + i}$$

约化拉格朗日量：对快时间 $\theta$ 积分 $L_0 = \int_{-\infty}^{+\infty} \mathcal{L}_0 \, d\theta$：

$$L_0(A, W, \phi) = -2 A^2 W \frac{d\phi}{dt} - \frac{d_2 A^2}{3 W} + \frac{2}{3} A^4 W - 2 \delta_0 A^2 W$$
稳态解析孤子参数
解析解

利用带广义力的欧拉-拉格朗日方程 $\frac{\partial L_0}{\partial q_j} - \frac{d}{dt}\left(\frac{\partial L_0}{\partial \dot{q}_j}\right) = 2\,\text{Re}\int \mathcal{R} \frac{\partial \psi_s^*}{\partial q_j} d\theta$，令稳态导数 $\dot{A} = \dot{W} = \dot{\phi} = 0$：

$$A = \sqrt{2\delta_0}, \quad W = \sqrt{\frac{d_2}{2\delta_0}}, \quad \cos\phi = \frac{2A}{\pi S} = \frac{2\sqrt{2\delta_0}}{\pi S}$$
峰值振幅 · 脉冲宽度 · 锁定相位

存在条件：稳定上支取 $\sin\phi > 0$，最小泵浦阈值：

$$S_{\min} = \frac{2\sqrt{2\delta_0}}{\pi}$$
孤子存在的最小泵浦阈值

完整解析近似解：

$$\psi_{\text{DKS}}(\theta) \approx \frac{iS}{-\delta_0 + i} + \sqrt{2\delta_0}\, \operatorname{sech}\left( \sqrt{\frac{2\delta_0}{d_2}} (\theta - \theta_0) \right) e^{i \arccos\left(\frac{2\sqrt{2\delta_0}}{\pi S}\right)}$$
CW 背景 + sech 孤子脉冲 = 完整稳态 DKS 解
4线性稳定性分析：分岔与呼吸子
鞍结分岔（Saddle-Node Bifurcation）
稳定性

引入孤子总能量 $E = A^2 W$，将 ODE 系统改写为自治动力系统 $\dot{\mathbf{X}} = \mathbf{F}(\mathbf{X})$（$\mathbf{X} = (E, W, \phi)^T$），雅可比矩阵特征多项式为：

$$\lambda^3 + c_2 \lambda^2 + c_1 \lambda + c_0 = 0$$
  • 下支（$\sin\phi_s < 0$）：$c_0 < 0$，至少一个正实部特征值 → 无条件不稳定。
  • 上支（$\sin\phi_s > 0$）：$c_0 > 0$，在 $S = S_{\min}$（即 $\phi_s = 0$）处与下支发生鞍结分岔。
Hopf 分岔与呼吸子（Breather）
呼吸子

随泵浦 $S$ 增大或失谐 $\delta_0$ 减小，上支孤子振荡失稳。根据 Routh-Hurwitz 判据，当特征多项式系数满足：

$$c_1 c_2 - c_0 = 0 \quad (\text{且 } c_1 > 0, c_2 > 0)$$
超临界 Hopf 分岔边界

雅可比矩阵一对共轭复特征值 $\lambda = \pm i\omega_H$ 穿越虚轴，稳态孤子的振幅 $A(t)$ 和脉宽 $W(t)$ 以频率 $\omega_H$ 周期性呼吸振荡，演化为呼吸子孤子（Breathing DKS）。

5数值求解方法
Newton-Raphson 稳态迭代法（理论参考）
稳态求解

将复光场拆分为实部与虚部 $\psi(\theta) = u(\theta) + iv(\theta)$，利用傅里叶谱微分矩阵 $\mathbf{D}_2$ 构造稳态代数残差方程 $\mathbf{F}(\mathbf{u}, \mathbf{v}) = \mathbf{0}$ 及其解析雅可比矩阵 $\mathbf{J}$：

$$\mathbf{F}_u = \frac{d_2}{2}\mathbf{D}_2 \mathbf{u} + (u^2+v^2)\mathbf{u} - \delta_0 \mathbf{u} - \mathbf{v}$$ $$\mathbf{F}_v = \frac{d_2}{2}\mathbf{D}_2 \mathbf{v} + (u^2+v^2)\mathbf{v} - \delta_0 \mathbf{v} + \mathbf{u} - S$$
分步傅里叶法（Strang Splitting SSFM，交互仿真采用）
动态演化

交互仿真器以变分解析解作为初值，采用二阶对称分步格式（Strang splitting）：线性部分（损耗+失谐+GVD+TOD）在频域精确推进，非线性部分（Kerr+泵浦）在时域以 RK2 半步对称推进：

$$\hat{L}(\mu) = -1 - i\delta_0 - \frac{id_2}{2}\mu^2 + \frac{id_3}{6}\mu^3$$
