2F-P 腔动力学方程

从离散往返模型到连续时间微分方程：LLE 与 GLE 的推导、归一化、稳态解与双稳态对比仿真

从离散干涉到连续动力学
原理

F-P 腔的传统描述基于离散往返的多光束干涉（Airy 函数）。当关注光场的时间演化而非稳态透射时，需要将离散的往返映射转化为连续时间的微分方程。

两条推导路径，各自侧重不同的物理视角，最终得到结构一致的线性微分方程：

  • 路径 A：等效谐振子模型 → LLE。将 F-P 腔类比为阻尼谐振子，在慢变包络近似下化为一阶 ODE。LLE 有外部泵浦驱动项 $S$，腔本身无增益。
  • 路径 B：Maxwell 波动方程 + 边界条件 → GLE。从 Maxwell 方程出发，将往返映射做 Taylor 展开连续化。GLE 无外部激励源，但可含增益和可饱和吸收。

统一形式：两条路径在纯线性极限下得到结构一致的方程 $\frac{d\psi}{dt} = (-\kappa + i\Delta)\psi + \text{(source)}$，稳态时退化为 Lorentzian 线型，与 Airy 函数在谐振峰附近一致。

图 1. 两条推导路径：A（等效谐振子 → LLE）与 B（Maxwell 方程 → GLE），收敛于统一线性方程

LLE vs GLE 关键区别：

  • LLE：被动腔，$S \neq 0$（外部驱动），无增益，色散/非线性系数为纯虚（仅相位调制）。
  • GLE：有源腔，$S = 0$（无外部驱动），含峰值增益 $g_{\text{pk}}$，色散/非线性系数为复数（实部=增益带宽/可饱和吸收，虚部=相位调制）。
路径 A：等效谐振子模型 → LLE
推导 A

第一步：F-P 腔 ↔ 阻尼谐振子类比 — 光场振幅 $A$ ↔ 位移，腔损耗率 $\kappa$ ↔ 阻尼，外部输入 $A_{\text{in}}$ ↔ 驱动力。

第二步：慢变包络近似（SVEA） — 将 $A(t) = \tilde{A}(t) e^{-i\omega_p t}$ 代入二阶方程，忽略 $\ddot{\tilde{A}}$，得到一阶方程：

$$\frac{dA}{dt} = (-\kappa + i\Delta)A + \sqrt{2\kappa_{\text{ex}}}\, A_{\text{in}}$$
LLE 基础方程：$\Delta = \omega_0 - \omega_p$，$\kappa = \kappa_{\text{ex}} + \kappa_{\text{int}}$

稳态解：$A_{\text{ss}} = \frac{\sqrt{2\kappa_{\text{ex}}} A_{\text{in}}}{\kappa - i\Delta}$，透射率 $T \propto \frac{1}{\kappa^2 + \Delta^2}$（Lorentzian 线型）。

符号约定说明：本章取 $\Delta = \omega_0 - \omega_p$（$+i\Delta A$ 与 Kerr 项 $+i\gamma|A|^2 A$ 同号，谐振峰向 $\Delta < 0$ 侧倾斜）；第 6 章采用标准微腔光频梳约定 $-\delta_0\psi$，两者仅相差一个负号。

路径 B：Maxwell 波动方程 → GLE
推导 B

第一步：从 Maxwell 方程得到包络传输方程 $\frac{\partial \mathcal{E}}{\partial z} + \frac{1}{v_g}\frac{\partial \mathcal{E}}{\partial t} = 0$。

第二步：F-P 腔往返映射 $E(t + T_R) = \sqrt{R}\, e^{i\Phi}\, E(t)$，其中 $T_R = 2nL/c$。

第三步：Taylor 展开 $E(t+T_R) \approx E + T_R \partial_t E$，代入往返映射：

$$\frac{\partial E}{\partial t} = \frac{\sqrt{R}\, e^{i\Phi} - 1}{T_R}\, E$$

第四步：识别参数 $\kappa = \frac{1-\sqrt{R}}{T_R}$，$\Delta = \frac{\Phi}{T_R}$，得到 GLE 基础方程：

$$\frac{\partial E}{\partial t} = (-\kappa + i\Delta)\, E$$
GLE 基础形式：无外部源，自由衰减
引入色散、增益与非线性
推广

LLE + 色散 + Kerr（被动腔，无增益）：

$$\frac{\partial A}{\partial t} = (-\kappa + i\Delta)A + i\frac{\beta_2}{2}\frac{\partial^2 A}{\partial \tau^2} + i\gamma|A|^2 A + S$$
完整 LLE：色散项和 Kerr 项均为纯虚（仅相位调制）

GLE + 增益带宽 + 可饱和吸收 + Kerr（有源腔）：

$$\frac{\partial E}{\partial t} = (-\kappa + g_{\text{pk}} + i\Delta)E + \left(-\frac{g_0}{2} + i\frac{\beta_2}{2}\right)\frac{\partial^2 E}{\partial \tau^2} + (-\alpha_s + i\gamma')|E|^2 E$$
完整 GLE：复色散系数 $\tilde{d}_0 = -g_0/2 + i\beta_2/2$，复非线性系数 $\tilde{n}_0 = -\alpha_s + i\gamma'$
归一化处理
归一化

LLE 归一化：$\psi = A\sqrt{\gamma/\kappa}$，$s = S\sqrt{\gamma/\kappa^3}$，$\tilde{t} = \kappa t$，$\delta = \Delta/\kappa$，$d_2 = \beta_2/\kappa$：

$$\frac{\partial \psi}{\partial \tilde{t}} = (-1 + i\delta)\psi + i\frac{d_2}{2}\frac{\partial^2 \psi}{\partial \tau^2} + i|\psi|^2\psi + s$$
归一化 LLE（$d_2 = \beta_2/\kappa$，保留 $\frac{1}{2}$ 因子）

GLE 归一化：$\epsilon = E\sqrt{\alpha_s/\kappa}$，$\mu = g_{\text{pk}}/\kappa$，$\tilde{d} = (-g_0 + i\beta_2)/(2\kappa)$，$\tilde{n} = -1 + i(\gamma'/\alpha_s)$：

$$\frac{\partial \epsilon}{\partial \tilde{t}} = (-1 + \mu + i\delta)\epsilon + \tilde{d}\,\frac{\partial^2 \epsilon}{\partial \tau^2} + \tilde{n}\,|\epsilon|^2\epsilon$$
归一化 GLE：$\mu > 1$ 时增益超过损耗，可起振
稳态解与 Airy 函数对比
稳态

取 CW 稳态（$\partial/\partial\tilde{t} = 0$），无非线性极限：

$$T_{\text{LLE}}^{(0)} = \frac{1}{1 + \delta^2}$$
线性极限：标准 Lorentzian 线型

含 Kerr 非线性时，Kerr 效应等效于失谐量的功率依赖修正 $\delta \to \delta + |\psi_0|^2$：

$$|s|^2 = |\psi_0|^2\left[1 + \left(\delta + |\psi_0|^2\right)^2\right]$$
含非线性的稳态方程：立方方程确定 $|\psi_0|^2$，可产生双稳态

Airy 函数在谐振峰附近退化为同一 Lorentzian：

$$T_{\text{Airy}} \xrightarrow{\text{near resonance}} \frac{1}{1 + \delta^2} = T_{\text{LLE}}^{(0)}$$
仿真算法：Cardano 立方求根与双稳态分支判定
数值算法

设归一化光强 $I = |\psi_0|^2$、Kerr 强度系数 $\chi$，稳态方程化为 $\chi^2 I^3 + 2\delta\chi I^2 + (1+\delta^2)I - |s|^2 = 0$。令 $I = u - \frac{2\delta}{3\chi}$ 化为缺项三次方程 $u^3 + pu + q = 0$，判别式 $\Delta_{\text{disc}} = -4p^3 - 27q^2$：

  • $\Delta_{\text{disc}} < 0$：单实根，用 Cardano 立方根公式求解。
  • $\Delta_{\text{disc}} \ge 0$：三正实根（双稳态区），用三角公式 $u_k = 2\sqrt{-p/3}\cos\left(\frac{1}{3}\arccos\frac{-q}{2\sqrt{(-p/3)^3}} + \frac{2\pi k}{3}\right)$ 求解并排序，最大/最小根为稳定上下支，中间根为不稳定中支。
