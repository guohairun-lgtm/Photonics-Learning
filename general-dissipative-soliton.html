7广义耗散孤子（三次-五次 CGLE / Kelly 边带 / 纯四次孤子）

三次-五次 CGLE 主方程 → 拉格朗日变分解析解 → 高阶色散与纯四次孤子（PQS）→ 分立腔 Round-Trip 映射与 Kelly 边带 → 自适应步长 SSFM-RK4 交互仿真

1从 Kerr 孤子到广义耗散孤子
CGLE：LLE 的推广
概述

第 6 章讨论的无源 Kerr 微腔耗散孤子由 Lugiato-Lefever 方程（LLE）描述，其非线性仅含三次 Kerr 项。当系统进一步引入五次非线性（饱和吸收/自聚焦修正）、增益饱和与谱滤波、高阶色散（三阶、四阶）等效应时，LLE 推广为三次-五次复 Ginzburg-Landau 方程（CGLE）。

  • 复数系数：方程系数含实部（色散/非线性）和虚部（增益/损耗），是真正的非哈密顿耗散系统。
  • 三次 + 五次非线性：$|u|^2 u$ 提供 Kerr 自相位调制，$|u|^4 u$ 提供五次饱和吸收——后者钳位高峰值功率，防止高能量脉冲坍缩。
  • 增益饱和与谱滤波：增益介质引入频率依赖的增益 $g(\omega)$，等效抛物线谱滤波 $\beta_f \partial^2/\partial\tau^2$。
  • 高阶色散：$d_3$（三阶）破坏光谱对称性，$d_4$（四阶）可支持纯四次孤子（PQS）。
图 1. 锁模激光腔的均匀场 CGLE 与分立 Round-Trip 映射及三类典型色散区域
均匀场模型 vs Round-Trip 映射
建模方法
  • 均匀场（Mean-Field）CGLE：将腔内所有元件效应平均到一个连续传播方程，适用于紧凑腔。局限：将分立输出耦合损耗平滑化，无法产生 Kelly 边带。
  • Round-Trip 映射（庞加莱映射）：将腔视为分立元件级联——先沿光纤传播，再施加集总输出耦合损耗 $\sqrt{1-l_{\text{out}}}$。稳态脉冲是不动点 $\mathcal{P}[u_0]e^{-i\phi_0} - u_0 = 0$，能精确捕捉 Kelly 边带。
2色散区域的多样性与 Kelly 边带
六种色散区域与孤子形态
物理图像
  • 纯四次孤子（PQS）：$|d_2|<0.08$ 且 $d_4<-0.1$，平顶脉冲带振荡指数尾，能量-脉宽三次反比律 $E \propto |d_4|/w^3$。
  • 混合二阶+四阶反常：$d_2 \le -0.08$ 且 $d_4<-0.1$，主瓣由二阶与四阶共同平衡，尾部随 $|d_4/d_2|$ 增大出现振荡。
  • 经典反常二阶色散：$d_2<-0.1$ 且 $d_4\ge-0.1$，sech/高斯型，啁啾小，指数单调衰减尾。
  • 弱/中等正常色散：$-0.1 \le d_2 \le 1.5$ 且 $d_4\ge-0.1$，强频率啁啾 $|C|\sim 1\text{--}3$，$d_3\neq 0$ 时光谱非对称。
  • 强正常色散 DSR 平顶：$d_2>1.5$ 或 $d_4>1.5$，陡峭边缘平顶矩形脉冲，峰值功率被五次饱和钳位。
  • 连续延拓模式：沿解分支连续演化，直接继承上一步收敛的精确解。
Kelly 边带：分立腔损耗诱导的色散波共振
物理现象

在 Round-Trip 映射框架下，每圈输出耦合器对孤子施加瞬态扰动并激发线性色散波。当色散波每圈累积色散相位满足 $\Phi_{\text{disp}}(\omega_m) - \phi_{\text{sol}} = 2m\pi$ 时，与后续扰动相干叠加、共振增强，在光谱主瓣两侧形成周期性尖峰——即 Kelly 边带。

3稳定性、数值方法与章节关联
不动点存在 ≠ 动力学稳定
稳定性

严格稳定性由 Bogoliubov-de Gennes（BdG）线性化算子特征值判定：$\max\,\text{Re}(\lambda) < 0$ 则扰动指数衰减（动力学稳定）；存在正实部特征值则失稳为呼吸子或崩溃。CGLE 是第 2 章 GLE 与第 6 章 LLE 的统一推广。

1均匀场 CGLE 及其归一化
有量纲广义三次-五次 CGLE
CGLE

当激光谐振腔单圈内脉冲演化步长远小于色散长度与非线性长度（平均场近似）时，光场慢变复包络 $A(z, t)$ 满足有量纲广义三次-五次 CGLE：

$$i \frac{\partial A}{\partial z} - \frac{\beta_2}{2}\frac{\partial^2 A}{\partial t^2} - i\frac{\beta_3}{6}\frac{\partial^3 A}{\partial t^3} + \frac{\beta_4}{24}\frac{\partial^4 A}{\partial t^4} + \gamma |A|^2 A = i g_0 A + i \beta_f \frac{\partial^2 A}{\partial t^2} + i \epsilon |A|^2 A - (i\mu - \nu)|A|^4 A$$
有量纲三次-五次 CGLE（Mean-Field Model）
  • 保守左端项：$\beta_2$（GVD，$\beta_2 < 0$ 反常，$\beta_2 > 0$ 正常）、$\beta_3$（TOD，破坏光谱对称性）、$\beta_4$（FOD，$\beta_4 < 0$ 支持纯四次孤子 PQS）、$\gamma > 0$（Kerr SPM）。
  • 耗散右端项：净线性增益/损耗 $g_0 = g_{\text{gain}} - l_0 < 0$（稳态抑制 CW 背景放大）；抛物线光谱滤波系数 $\beta_f = g_{\text{gain}}/\Omega_g^2 > 0$（由有源增益 $g_{\text{gain}} > 0$ 与增益带宽 $\Omega_g$ 决定）；$\epsilon > 0$（三次可饱和吸收）；$\mu > 0$（五次饱和吸收钳位）；$\nu$（五次非线性折射率修正）。
无量纲归一化推导
归一化

引入特征时间尺度 $T_0$、参考色散长度 $L_D$ 与特征峰值功率 $P_0$：

$$\tau = \frac{t}{T_0}, \qquad \xi = \frac{z}{L_D}, \qquad u(\xi, \tau) = \frac{A(z, t)}{\sqrt{P_0}}$$
$$P_0 = \frac{1}{\gamma L_D}, \qquad L_D = \frac{T_0^2}{|\beta_{2,\text{ref}}|} \quad \text{（PQS 取 } L_D = \frac{T_0^4}{|\beta_{4,\text{ref}}|}\text{）}$$
$$d_2 = \frac{\beta_2 L_D}{T_0^2}, \quad d_3 = \frac{\beta_3 L_D}{T_0^3}, \quad d_4 = \frac{\beta_4 L_D}{T_0^4}$$ $$\tilde{g}_0 = g_0 L_D, \quad \tilde{\beta}_f = \frac{\beta_f L_D}{T_0^2}, \quad \tilde{\epsilon} = \epsilon P_0 L_D, \quad \tilde{\mu} = \mu P_0^2 L_D$$

略去波浪号，得到无量纲归一化广义 CGLE 主方程：

$$i \frac{\partial u}{\partial \xi} - \frac{d_2}{2}\frac{\partial^2 u}{\partial \tau^2} - i\frac{d_3}{6}\frac{\partial^3 u}{\partial \tau^3} + \frac{d_4}{24}\frac{\partial^4 u}{\partial \tau^4} + |u|^2 u = i g_0 u + i \beta_f \frac{\partial^2 u}{\partial \tau^2} + i \epsilon |u|^2 u - (i\mu - \nu)|u|^4 u$$
无量纲归一化 CGLE 主方程
2经典二阶耗散孤子的变分法解析解
步骤一至三：保守拉格朗日密度、啁啾高斯试探解与约化拉格朗日量
Step 1–3

令 $d_3 = d_4 = 0$，记 $D = -d_2$（$D > 0$ 反常，$D < 0$ 正常），方程为 $i\frac{\partial u}{\partial \xi} + \frac{D}{2}\frac{\partial^2 u}{\partial \tau^2} + \gamma|u|^2 u = iR(u, u^*)$，其中 $R = g_0 u + \beta_f \frac{\partial^2 u}{\partial \tau^2} + \epsilon|u|^2 u - (\mu + i\nu)|u|^4 u$。

$$\mathcal{L}_0 = \frac{i}{2}\left( u^* \frac{\partial u}{\partial \xi} - u \frac{\partial u^*}{\partial \xi} \right) - \frac{D}{2}\left| \frac{\partial u}{\partial \tau} \right|^2 + \frac{\gamma}{2}|u|^4$$
保守拉格朗日密度 $\mathcal{L}_0$
$$u(\xi, \tau) = \sqrt{\frac{E(\xi)}{\sqrt{\pi}\,w(\xi)}} \exp\left( -\frac{\tau^2}{2w(\xi)^2} + i\frac{C(\xi)}{2w(\xi)^2}\tau^2 + i\phi(\xi) \right)$$
啁啾高斯试探解（能量 $E = \sqrt{\pi}Pw$，脉宽 $w$，啁啾 $C$，相位 $\phi$）
$$L = -E \frac{d\phi}{d\xi} - \frac{E}{4}\frac{dC}{d\xi} + \frac{EC}{2w}\frac{dw}{d\xi} - \frac{DE}{4w^2}(1 + C^2) + \frac{\gamma E^2}{2\sqrt{2\pi}\,w}$$
约化拉格朗日量（Averaged Lagrangian）
步骤四：修正欧拉-拉格朗日方程 → ODE 系统
Step 4
$$\frac{\partial L}{\partial q_j} - \frac{d}{d\xi}\left(\frac{\partial L}{\partial \dot{q}_j}\right) = 2\,\text{Re}\int_{-\infty}^{\infty} i R(u, u^*) \frac{\partial u^*}{\partial q_j} \, d\tau, \quad q_j \in \{\phi, C, w, E\}$$
$$\frac{dE}{d\xi} = 2g_0 E - \frac{\beta_f E}{w^2}(1 + C^2) + \frac{\sqrt{2}\,\epsilon E^2}{\sqrt{\pi}\,w} - \frac{2\mu E^3}{\sqrt{3}\pi\,w^2}$$
能量演化方程（$\phi$ 变分）
$$\frac{dw}{d\xi} = \frac{DC}{w} + \frac{\beta_f}{w}(1 - C^2) - \frac{\epsilon E}{2\sqrt{2\pi}} + \frac{2\mu E^2}{3\sqrt{3}\pi\,w}$$
脉宽演化方程（$C$ 变分 + 能量方程联立）
$$\frac{dC}{d\xi} = \frac{D}{w^2}(1 + C^2) - \frac{4\beta_f C}{w^2} - \frac{\gamma E}{\sqrt{2\pi}\,w} + \frac{4\nu E^2}{3\sqrt{3}\pi\,w^2}$$
啁啾演化方程（$w$ 变分）
步骤五：稳态固定点闭合解析解
Step 5

令 $\dot{E} = \dot{w} = \dot{C} = 0$，定义归一化峰值功率 $P \equiv E/(\sqrt{\pi}\,w)$（取 $\nu = 0$）：

$$A_c C^2 + B_c C - A_c = 0, \quad A_c = 3\sqrt{2}\,\beta_f\gamma - \sqrt{2}\,D\epsilon, \quad B_c = 2\sqrt{2}\,D\gamma + 6\sqrt{2}\,\beta_f\epsilon$$
$$C = \frac{-B_c \pm \sqrt{B_c^2 + 4A_c^2}}{2A_c}, \qquad P = \frac{3\sqrt{3}}{2\mu} \left[ \frac{\epsilon}{\sqrt{2}} - \frac{2\beta_f(1 - C^2) + 2DC}{D(1 + C^2) - 4\beta_f C} \cdot \frac{\gamma}{\sqrt{2}} \right]$$
$$w = \sqrt{\frac{\beta_f(1 + C^2)}{2g_0 + \sqrt{2}\,\epsilon P - \frac{2\mu}{\sqrt{3}} P^2}}, \qquad E = \sqrt{\pi}\,P\,w, \qquad k = \frac{d\phi}{d\xi} = \frac{\gamma P}{\sqrt{2}} - \frac{D(1 + C^2)}{4w^2}$$

存在四大充要条件：$g_0 < 0$（背景稳定）、$P > 0$（正峰值）、$2g_0 + \sqrt{2}\epsilon P - \frac{2\mu}{\sqrt{3}}P^2 > 0$（实脉宽）、BdG $\max\,\text{Re}(\lambda) < 0$（动力学稳定）。

Kelly
$$A\big((n+1)L^+, t\big) = \sqrt{1 - l_{\text{out}}} \cdot A\big((n+1)L^-, t\big), \qquad \mathbf{F}(A_0, \phi_0) = \mathcal{P}[A_0](t)\, e^{-i\phi_0} - A_0(t) = 0$$

5简化三次 CGLE 变分法解析解、稳定性与 SSFM 算法
含全局增益饱和的简化三次 CGLE 与三维自治 ODE
简化模型

符号映射说明：本节与交互仿真器关闭五次项（$\mu = \nu = 0$）并记 $(\xi, \tau, u, -d_2, \beta_f, \epsilon) \to (z, t, \psi, D, \beta, \varepsilon)$，引入全局脉冲能量饱和 $\delta_{\text{eff}}(E) = \frac{g_0}{1 + E/E_s} - l_0$（Haus 主方程形式）：

$$i\frac{\partial \psi}{\partial z} + \frac{D}{2}\frac{\partial^2 \psi}{\partial t^2} + |\psi|^2 \psi = i Q, \qquad Q = \delta_{\text{eff}}(E)\psi + \beta\frac{\partial^2 \psi}{\partial t^2} + \varepsilon |\psi|^2 \psi$$

取试探解 $\psi(z, t) = A(z)\exp\left[-\frac{t^2}{2W(z)^2} + i C(z) t^2 + i \phi(z)\right]$（$E = \sqrt{\pi}A^2 W$），得平均拉格朗日量与三维自治 ODE 组：

$$L = \sqrt{\pi} A^2 W \left[ -\phi' - \frac{1}{2}W^2 C' - \frac{D}{4}\left(\frac{1}{W^2} + 4C^2 W^2\right) + \frac{A^2}{2\sqrt{2}} \right]$$
$$\frac{dA}{dz} = \delta_{\text{eff}}(E) A - D C A - \frac{\beta}{W^2} A + \frac{5\varepsilon}{4\sqrt{2}} A^3$$ $$\frac{dW}{dz} = 2 D C W + \beta\left(\frac{1}{W} - 4 C^2 W^3\right) - \frac{\varepsilon}{2\sqrt{2}} A^2 W$$ $$\frac{dC}{dz} = \frac{D}{2W^4} - 2 D C^2 - \frac{A^2}{2\sqrt{2}W^2} - \frac{4\beta C}{W^2}$$
全色散区统一精确解析解与三层稳定性判据
Analytical

引入无量纲啁啾 $q = 2CW^2$ 与参量 $P = A^2W^2/\sqrt{2}$，得全色散区无奇点精确解：

$$(2\beta - \varepsilon D) q^2 - 2(D + 2\varepsilon\beta) q - (2\beta - \varepsilon D) = 0$$ $$q = \frac{-(2\beta - \varepsilon D)}{(D + 2\varepsilon\beta) + \sqrt{(D + 2\varepsilon\beta)^2 + (2\beta - \varepsilon D)^2}}, \qquad P = D(1 - q^2) - 4\beta q$$
$$h(E) \equiv \frac{g_0}{1 + E/E_s} - l_0 + \frac{\Gamma}{2\pi P^2} E^2 = 0, \qquad \Gamma = \frac{5\varepsilon}{4}P - \beta - \frac{Dq}{2}$$ $$W_0 = \frac{\sqrt{2\pi} P}{E_0}, \qquad A_0 = \frac{(\sqrt{2} P)^{1/2}}{W_0}, \qquad C_0 = \frac{q}{2 W_0^2}$$

系统稳定性三层判据：

  • 动力学线性稳定性：$3\times 3$ 雅可比矩阵（计入 $\frac{\partial \delta_{\text{eff}}}{\partial A} = -\frac{2g_0 E}{AE_s(1+E/E_s)^2}$ 与 $\frac{\partial \delta_{\text{eff}}}{\partial W} = -\frac{g_0 E}{WE_s(1+E/E_s)^2}$）满足 $\max\,\text{Re}(\lambda_i) < 0$。
  • 能量分支稳定性：$h(E_{\min}) \le 0$ 时两根中下分支 $E_1$（$h' < 0$）稳定，上分支 $E_2$（$h' > 0$）不稳定。
  • 背景连续波稳定性：要求 $\delta_{\text{eff}}(E_0) < 0$，避免零背景噪声指数放大。
仿真算法：非均匀分立腔 Round-Trip 映射与自适应步长 SSFM-RK4
数值算法

交互仿真器在严格傅里叶网格（$N = 1024,\; T_{\max} = 64,\; \Delta t = 0.125,\; \Delta\omega = \pi/64 \approx 0.0491$）上对含二/三/四阶色散与三次-五次非线性的广义 CGLE 执行 1000 圈长程演化：

  • 自适应初值匹配与背景稳态：根据 $(d_2, d_4, \varepsilon, \mu, \beta_f)$ 自动匹配反常 sech、纯四次标度 sech 或正常色散强啁啾超高斯初值，并结合全局能量增益饱和抑制 CW 背景放大与多脉冲分裂。
  • Strang 分裂 + 时域 RK4 + 防数值共振自适应步长：每圈内动态选取步数 $M \in [20, 180]$ 使单步最大色散相移 $|\beta(\omega)|\,\Delta z < 0.65\pi$，彻底消除高阶色散下的 SSFM 数值步长虚假边带；时域采用四阶龙格-库塔法（RK4）精确积分三次-五次非线性项。
  • 分立腔 vs 均匀场与双共振标定：Round-Trip 模式下每圈末端施加集总输出耦合损耗 $\sqrt{1-l_{\text{out}}}$ 激发 Kelly 边带（$m \ge 1$），Mean-Field 模式下平滑均摊损耗；同时标出 $m = 0$ 切伦科夫色散波（DW）解析共振线，并采用超高斯吸收边界与随动居中机制保证 1000 圈长程稳定。
