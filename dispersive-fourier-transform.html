1空时对偶：从远场夫琅禾费衍射到色散傅里叶变换（DFT）
时间拉伸光谱测量与单发实时动力学探测
物理图像

在空间波动光学中，光束穿过狭缝后经充分长距离自由传播（远场夫琅禾费区），二次空间相位项将孔径场的空间傅里叶变换直接映射到远场光强分布上。由麦克斯韦傍轴衍射方程与色散脉冲传输方程（第 11 章 GNLSE 的线性极限）的数学同构性，这一过程在时间域存在精确的空时对偶（Space-Time Duality）：当超快脉冲穿过一段大群速度色散（GVD）传输介质（如长距离单模光纤 SMF-28、色散补偿光纤 DCF 或啁啾光纤布拉格光栅 CFBG）后，不同频率分量因群速度差异在时间轴上线性分离；在鞍点近似（稳相近似）成立的远场条件下，光纤输出端的时域光强包络 $|A(L, T)|^2$ 就是入射脉冲光谱 $|\tilde{A}(0, \omega)|^2$ 的实时“时间副本”。

将输出光接入单个高速光电探测器与实时示波器，即可在激光脉冲的原始重复频率（$10\text{--}500\,\text{MHz}$）下逐脉冲连续记录单发实时光谱（Single-Shot Real-Time Spectroscopy），填补了高速非重复瞬态动力学（如锁模起振过程、孤子分子振动、怪波 Rogue Wave、呼吸子失稳）实时观测的关键空白。

2实际商用色散光纤选型与数公里长度的工程权衡
为何实验 DFT 通常需要数公里至数十公里光纤？商用光纤参数对照
工程选型

在真实实验系统中，决定色散光纤长度 $L$ 的不仅有远场夫琅禾费判据（$L \ge 4 L_{D,\text{eff}}$，对皮秒脉冲往往只需数百米），更关键的工程约束来自高速光电探测器与实时示波器的电学带宽 $B_{\text{PD}}$（典型 $10\text{--}40\,\text{GHz}$）。由时间-波长映射 $\Delta T \approx |DL|\,\Delta\lambda$，探测器有限响应时间 $\delta t_{\text{PD}} \approx 1/B_{\text{PD}}$ 对应的光谱分辨率为 $\delta\lambda_{\text{PD}} \approx (|DL|\,B_{\text{PD}})^{-1}$。要实现 $0.05\text{--}0.3\,\text{nm}$ 的单发精细光谱分辨（例如分辨孤子分子的干涉条纹或 Kelly 边带），光纤总累积色散量通常必须达到 $|DL| \approx 150\text{--}1000\,\text{ps/nm}$，因此实验上常规需要 $2\text{--}25\,\text{km}$ 的商用光纤：

3鞍点近似与 GNLSE 一致性的五大失效机理
何时鞍点近似失效？五维物理判定准则
有效性分析

在真实长距离光纤链路（由完整 GNLSE 控制）中，只有当输入脉冲参数与光纤色散、损耗、非线性同时落入有效工作窗口时，鞍点近似才与 GNLSE 高度一致并真实反映原始光谱：

  • ① 远场夫琅禾费判据（色散长度下限）：要求 $D_{\text{FF}} = L / L_{D,\text{eff}} \gg 1$（典型 $D_{\text{FF}} \ge 4$）。若光纤过短，脉冲仍处于菲涅耳近场，时域波形保留原脉冲结构（如双脉冲尚未演化出光谱干涉条纹），远场近似失效。
  • ② 弱非线性与反孤子判据（功率上限）：在正常色散 DCF（$\beta_2 > 0$）中，高功率强 SPM 引发剧烈光谱展宽与光波分裂，输出光谱偏离入射真谱（$R_{\text{spec}}$ 暴跌）；在反常色散 SMF-28（$\beta_2 < 0$）中，当孤子数 $N = \sqrt{L_D\gamma P_0} \gtrsim 0.65$ 时，Kerr 自聚焦抵消色散展宽形成孤子自束缚，脉冲拒绝被拉伸，DFT 失效。
  • ③ 三阶色散（TOD）畸变判据：当脉冲极短或使用 NZ-DSF 等近零色散光纤时，$\eta_{\text{TOD}} = |\beta_3|\Delta\omega / (2|\beta_2|)$ 显著增大。中等 TOD（$0.06 \sim 0.40$）使线性映射刻度弯曲偏移，但启用含 $\beta_3$ 修正的非线性鞍点定标与雅可比幅值补偿仍可高保真救回光谱；若 $\eta_{\text{TOD}} \ge 0.40$ 跨越零色散点，群延迟曲线折返形成焦散重叠，单值时频映射崩溃。
  • ④ 相邻脉冲重叠判据（长度/重频上限）：展宽后的脉冲全宽 $T_{\text{out}}$ 必须小于重复周期 $T_{\text{rep}} = 1/f_{\text{rep}}$（占空比 $\xi_{\text{ov}} = T_{\text{out}} f_{\text{rep}} < 0.70$），否则相邻脉冲首尾交叠造成帧间混叠。
  • ⑤ 传输损耗与拉伸峰值信噪比判据（功率下限）：数公里至数十公里光纤引入指数损耗 $e^{-\alpha_{\text{lin}} L}$，叠加色散大倍率拉伸导致的峰值功率反比下跌 $\propto 1/M$，若输出峰值 $P_{\text{out,pk}}$ 跌近高速 PD 噪声基底（$P_{\text{NEP}} \approx 2\,\mu\text{W}$），单发光谱将被噪声淹没（工程中常采用分布式拉曼放大来补偿长 DCF 损耗）。

1GNLSE 基准方程与商用光纤 $(D, S) \leftrightarrow (\beta_2, \beta_3)$ 精确换算
真实光纤传输方程及工程色散参量换算推导
基准方程

在随动时间坐标系 $T = t - \beta_1 z$ 下，中心波长 $\lambda_0 = 1550\,\text{nm}$（$\omega_0 = 2\pi c/\lambda_0 \approx 1215.2\,\text{rad/ps}$）处的超快光脉冲复包络 $A(z, T)$ 遵循通用非线性薛定谔方程（GNLSE）：

$$\frac{\partial A}{\partial z} = -\frac{\alpha_{\text{lin}}}{2}A - i\frac{\beta_2}{2}\frac{\partial^2 A}{\partial T^2} + \frac{\beta_3}{6}\frac{\partial^3 A}{\partial T^3} + i\gamma\!\left(1 + \frac{i}{\omega_0}\frac{\partial}{\partial T}\right)\!\left[A\!\left(|A|^2 - \tau_R\frac{\partial |A|^2}{\partial T}\right)\right]$$ $$\alpha_{\text{lin}} = \alpha_{\text{dB}}\frac{\ln 10}{10}, \qquad P_{\text{avg}} = f_{\text{rep}} E_p = f_{\text{rep}}\int_{-\infty}^{+\infty}|A(0, T)|^2\,\mathrm{d}T$$

商用光纤规格书通常给出波长域的群速度色散参量 $D = \frac{\mathrm{d}\beta_1}{\mathrm{d}\lambda}$（单位 $\text{ps/(nm}\cdot\text{km)}$）和色散斜率 $S = \frac{\mathrm{d}D}{\mathrm{d}\lambda}$（单位 $\text{ps/(nm}^2\cdot\text{km)}$）。利用 $\omega = \frac{2\pi c}{\lambda}$ 与 $\frac{\mathrm{d}}{\mathrm{d}\lambda} = -\frac{2\pi c}{\lambda^2}\frac{\mathrm{d}}{\mathrm{d}\omega}$，对 $D = -\frac{2\pi c}{\lambda^2}\beta_2$ 再求一次波长导数：

$$S = \frac{\mathrm{d}D}{\mathrm{d}\lambda} = \frac{4\pi c}{\lambda^3}\beta_2 + \left(\frac{2\pi c}{\lambda^2}\right)^2\beta_3 = -\frac{2}{\lambda}D + \left(\frac{2\pi c}{\lambda^2}\right)^2\beta_3$$ $$\Longrightarrow \quad \beta_2 = -\frac{\lambda_0^2}{2\pi c}\,D, \qquad \beta_3 = \left(\frac{\lambda_0^2}{2\pi c}\right)^2\!\left(S + \frac{2D}{\lambda_0}\right)$$
在 $\lambda_0 = 1550\,\text{nm}$ 处，$\frac{\lambda_0^2}{2\pi c} \approx 1.2754\,\text{ps}\cdot\text{nm}$：SMF-28 ($D=+17, S=+0.088$) 给出 $\beta_2=-21.7, \beta_3=+0.18$；全斜率 C 波段 DCF ($D=-102, S=-0.36$) 给出 $\beta_2=+130.1, \beta_3=-0.80$
2鞍点近似（稳相法）、波长域非均匀定标与分辨率工程设计
驻相积分展开、雅可比幅值修正与多公里总色散设计方程
鞍点推导

在弱非线性极限（$\gamma \to 0$）下，采用傅里叶约定 $\tilde{A}(z, \omega) = \int_{-\infty}^{+\infty} A(z, T)e^{+i\omega T}\mathrm{d}T$，线性色散传输的精确解为振荡积分：

$$A_{\text{lin}}(L, T) = \frac{e^{-\alpha_{\text{lin}} L/2}}{2\pi}\int_{-\infty}^{+\infty} \tilde{A}(0, \omega)\,\exp\!\big[i\,\Phi(\omega; T)\big]\,\mathrm{d}\omega, \qquad \Phi(\omega; T) \equiv \frac{\beta_2 L}{2}\omega^2 + \frac{\beta_3 L}{6}\omega^3 - \omega T$$

令驻相条件 $\Phi'(\omega_s) = 0$ 并将相位展开至二阶 $\Phi(\omega) \approx \Phi(\omega_s) + \frac{1}{2}\Phi''(\omega_s)(\omega - \omega_s)^2$，由菲涅耳高斯积分直接给出两级解析近似：

$$\text{（A）纯二阶线性鞍点：}\quad \omega_{\text{lin}}(T) = \frac{T}{\beta_2 L}, \qquad |A_{\text{SP,lin}}(L, T)|^2 = \frac{e^{-\alpha_{\text{lin}} L}}{2\pi |\beta_2| L}\left|\tilde{A}\!\left(0,\, \frac{T}{\beta_2 L}\right)\right|^2$$ $$\text{（B）含 TOD 修正的非线性鞍点：}\quad \omega_s(T) = \frac{-\beta_2 + \operatorname{sgn}(\beta_2)\sqrt{\beta_2^2 + \frac{2\beta_3 T}{L}}}{\beta_3}, \qquad |A_{\text{SP,TOD}}(L, T)|^2 = \frac{e^{-\alpha_{\text{lin}} L}}{2\pi\, L\sqrt{\beta_2^2 + \frac{2\beta_3 T}{L}}}\left|\tilde{A}\!\big(0,\, \omega_s(T)\big)\right|^2$$
雅可比因子 $|\Phi''(\omega_s)| = L|\beta_2 + \beta_3\omega_s| = L\sqrt{\beta_2^2 + 2\beta_3 T/L}$；当 $\beta_2^2 + 2\beta_3 T/L \le 0$ 时形成焦散边界，单值映射崩溃

波长域映射关系与数公里光纤长度需求：等价地在波长偏移 $\Delta\lambda = \lambda - \lambda_0$ 下展开群延迟，并联合高速光电探测器带宽 $B_{\text{PD}}$（典型 $25\,\text{GHz}$）确定总光谱分辨率：

$$\Delta T(\Delta\lambda) = D L\,\Delta\lambda + \frac{1}{2} S L\,(\Delta\lambda)^2, \qquad \delta\lambda_{\text{disp}} \approx \lambda_0\sqrt{\frac{2}{c\,|D L|}}, \qquad \delta\lambda_{\text{PD}} = \frac{1}{|D L|\,B_{\text{PD}}}$$ $$L \ge \max\!\left(4\,L_{D,\text{eff}},\;\; \frac{1}{|D|\,B_{\text{PD}}\,\delta\lambda_{\text{target}}}\right)$$
例：欲在 $B_{\text{PD}} = 25\,\text{GHz}$ 下获得 $\delta\lambda_{\text{PD}} \le 0.25\,\text{nm}$ 分辨率，需 $|DL| \ge 160\,\text{ps/nm}$，对应 $L_{\text{SMF-28}} \ge 9.4\,\text{km}$ 或 $L_{\text{C-DCF}} \ge 1.6\,\text{km}$
3有效工作窗口解析边界与两阶段混合 GNLSE-Fresnel 算法
2D 相图边界与面向 $L = 10\text{--}30\,\text{km}$ 大拉伸比的无混叠精确求解
核心算法

一、$(\log_{10} L,\; \log_{10} P_0)$ 平面有效窗口四边界：

$$L \ge 4\,L_{D,\text{eff}} = \frac{16\,T_{\text{rms}}^2}{|\beta_2|} \;\text{（远场下限）}, \qquad L \le \frac{0.70}{f_{\text{rep}}|\beta_2|\Delta\omega_{\text{full}}} \;\text{（防重叠上限）}$$ $$P_0 \le \frac{0.30}{\gamma L_D\,\operatorname{arsinh}(L_{\text{eff}}/L_D)} \;\text{（弱非线性上限，反常区另需 } P_0 \le \frac{0.36}{\gamma L_D}\text{）}, \qquad P_0 \ge 10^{1.8} P_{\text{NEP}}\,e^{\alpha_{\text{lin}} L}\sqrt{1 + (L/L_D)^2}$$

二、两阶段混合自适应 GNLSE + 单步精确 Fresnel 变换算法（突破数十公里网格瓶颈）：在 $L = 10\text{--}30\,\text{km}$ 真实光纤中，脉冲时间拉伸比 $M$ 可达数百至上千倍，若全程在单一固定等间距 FFT 网格上积分，同时解析入纤皮秒脉冲与出纤纳秒波形需 $N > 2^{17}$ 点。仿真器利用超快脉冲非线性作用高度局域在光纤前段的物理特性，将传输严格分解为两阶段：

  1. 阶段一（活跃非线性区 $0 \to z_{\text{nl}}$）：在精细时域网格（$N \in \{4096, 8192, 16384\}$，$\Delta t \le T_0/4$）上以自适应步长 Strang 分裂 SSFM 求解完整 GNLSE（含 $\alpha, \beta_2, \beta_3$、SPM、拉曼与自陡峭）。当脉冲充分展宽使剩余非线性相移 $\gamma P_{\text{pk}}(z)(L-z) < 0.015\,\text{rad}$ 或接近阶段一窗口边缘时退出（若为反常色散孤子束缚态，脉冲不展宽则自动保持全段 SSFM 推进）。
  2. 阶段二（长程纯线性色散区 $z_{\text{nl}} \to L$，$\Delta z = L - z_{\text{nl}}$）：先在频域精确施加三阶色散相位 $\exp\!\left(i\frac{\beta_3\Delta z}{6}\omega^3\right)$ 得到 $A_{\text{tod}}(z_{\text{nl}}, t')$，再对大二阶色散 $\beta_2\Delta z$ 实施数学上严格精确的单步 Fresnel 因子化傅里叶变换：
    $$A_{\text{lin}}(L, T) = \frac{e^{-\alpha_{\text{lin}}\Delta z/2 + i\operatorname{sgn}(\beta_2\Delta z)\frac{\pi}{4}}}{\sqrt{2\pi |\beta_2 \Delta z|}}\,e^{-i\frac{T^2}{2\beta_2 \Delta z}} \int_{-\infty}^{+\infty}\!\left[A_{\text{tod}}(z_{\text{nl}}, t')\,e^{-i\frac{t'^2}{2\beta_2 \Delta z}}\right] e^{+i\left(\frac{T}{\beta_2\Delta z}\right)t'}\,\mathrm{d}t'$$
    当 $|\beta_2\Delta z|$ 极大时，内部二次相位 $e^{-i t'^2/(2\beta_2\Delta z)}$ 缓变无混叠，仅需单次 $N=4096$ FFT 即可在毫秒级精确还原 $L=30\,\text{km}$ 输出波形（与 $N=65536$ 暴力网格相关度 $>0.999999$），且在 $|\beta_2\Delta z|\to\infty$ 时自然过渡至鞍点近似极限
