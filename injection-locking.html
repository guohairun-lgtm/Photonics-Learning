4激光注入锁定

单谐振峰激光模型 → 外部连续光注入锁定 → Adler 方程、非对称锁定带宽与实时相位演化

单谐振峰激光模型
原理

为聚焦注入锁定效应，采用单纵模激光模型。在第三章载流子-光子速率方程的基础上做关键简化：载流子动态视为已达稳态，增益系数正比于注入电流，光场用复振幅描述（保留相位信息——这是分析注入锁定不可或缺的）。

电流-频率红移效应：增大注入电流引起两个竞争效应——载流子浓度升高使折射率下降（频率蓝移），热效应使折射率增大（频率红移）。大多数半导体激光器中热效应占主导，净效应为随电流增大频率红移：$\omega_c(I) = \omega_{c0} - \alpha_T(I - I_{\text{th}})$。

自由运行稳态：无外部注入时，稳态要求增益 = 损耗（$G = \gamma$），激光以电流决定的腔谐振频率 $\omega_c(I)$ 自由振荡。引入增益饱和限制光场幅度，这是激光稳态存在的必要条件。

与第三章的联系：第三章速率方程描述 $S = |E|^2$ 的强度演化（无相位），此处保留复振幅 $E$ 以分析注入锁定中的相位同步。增益从载流子函数 $g(N)$ 简化为电流控制的常数 $G_0$。

激光注入锁定：外部光场驱动同步
注入锁定

一束外部连续光（主激光器，频率 $\omega_{\text{inj}}$）通过光隔离器注入从激光腔。当注入光频率落在激光腔的锁定带宽内时，从激光的振荡频率被强制同步到注入光频率——这就是注入锁定。

图 1. 注入锁定系统结构：主激光器经隔离器注入从激光腔，锁定后输出频率 = 注入光频率

锁定机制：注入项 $\kappa_{\text{inj}} E_{\text{inj}}$ 是一个恒定复数驱动力（在旋转系中），同时提供能量（振幅驱动）和相位参考（频率牵引）。稳态锁定时激光输出频率完全等于注入光频率。

锁定带宽：锁定存在的条件是 $|\Delta\omega| < \Delta\omega_{\text{lock}}$，其中 $\Delta\omega_{\text{lock}} = \kappa_{\text{inj}}(E_{\text{inj}}/E_0)\sqrt{1+\alpha_H^2}$。注入越强、Henry 因子越大，锁定范围越宽。锁定区外进入拍频态。

Adler 方程视角：将方程写成相位形式 $\dot{\phi} = -\Delta\omega + \kappa_{\text{inj}}(E_{\text{inj}}/E_0)\sin(\phi_{\text{inj}} - \phi)$，这正是经典的 Adler 方程——描述受驱动振荡器的相位同步。

单谐振峰激光方程
基础

增益正比于注入电流，载流子已达稳态，计入增益饱和与线宽增强因子（Henry 因子）$\alpha_H$：

$$\frac{dE}{dt} = \left[\frac{1}{2}(1 + i\alpha_H)\left(\frac{G_0}{1+|E|^2/E_{\text{sat}}^2} - \gamma\right) + i\omega_c(I)\right]E$$
$G_0 \propto I_{\text{bias}} - I_{\text{th}}$，$\gamma = 1/\tau_p$，$\omega_c(I) = \omega_{c0} - \alpha_T(I-I_{\text{th}})$

自由运行稳态（$G = \gamma$）：

$$|E_0|^2 = E_{\text{sat}}^2\left(\frac{G_0}{\gamma} - 1\right), \quad \omega_{\text{free}} = \omega_c(I)$$
注入锁定方程与旋转变换
注入锁定

加入外部注入光场项：

$$\frac{dE}{dt} = \left[\frac{1}{2}(1 + i\alpha_H)(G - \gamma) + i\omega_c\right]E + \kappa_{\text{inj}} E_{\text{inj}} e^{i\omega_{\text{inj}} t}$$

旋转变换 $E(t) = \tilde{E}(t) e^{i\omega_{\text{inj}} t}$，消去公共旋转项：

$$\frac{d\tilde{E}}{dt} = \left[\frac{1}{2}(1 + i\alpha_H)(G - \gamma) - i\Delta\omega\right]\tilde{E} + \kappa_{\text{inj}} E_{\text{inj}}$$
$\Delta\omega = \omega_{\text{inj}} - \omega_c(I)$，$\tilde{E}$ 在注入光参考系中
稳态锁定解与 Adler 方程
稳态

稳态锁定解（$d\tilde{E}/dt = 0$）：

$$\tilde{E}_{\text{ss}} = \frac{\kappa_{\text{inj}} E_{\text{inj}}}{\frac{1}{2}(1+i\alpha_H)(\gamma - G) + i\Delta\omega}$$
锁定时输出频率 = $\omega_{\text{inj}}$

Adler 方程（令 $\tilde{E} = E_0 e^{i\phi}$，在弱注入下绝热消去振幅微扰）：

$$\frac{d\phi}{dt} = -\Delta\omega - \kappa_{\text{inj}}\frac{E_{\text{inj}}}{E_0}\left[\sin\phi + \alpha_H\cos\phi\right] = -\Delta\omega - \kappa_{\text{inj}}\frac{E_{\text{inj}}}{E_0}\sqrt{1+\alpha_H^2}\,\sin\big(\phi + \arctan\alpha_H\big)$$
$\alpha_H$ 为 Henry 因子，$\phi$ 为激光场相对注入场的相位差
锁定带宽与非对称稳定性边界
带宽

锁定带宽（Adler 存在范围，含 Henry 因子修正）：

$$\Delta\omega_{\text{lock}} = \kappa_{\text{inj}}\frac{E_{\text{inj}}}{E_0}\sqrt{1 + \alpha_H^2}$$
锁相解存在条件：$|\Delta\omega| < \Delta\omega_{\text{lock}}$

物理含义与非对称性：

  • 注入强度 $\kappa_{\text{inj}} E_{\text{inj}} / E_0$ 越大，锁定带宽越宽。
  • Henry 因子 $\alpha_H \sim 2\text{--}7$ 使锁定存在范围扩大 $\sqrt{1+\alpha_H^2}$ 倍。
  • 考虑静态幅度-相位稳定性（增益不能高于自由运行阈值）后，正负失谐锁定边界呈非对称分布：$-\Delta\omega_{\text{lock}} < \Delta\omega < +\kappa_{\text{inj}}\frac{E_{\text{inj}}}{E_0}$。
