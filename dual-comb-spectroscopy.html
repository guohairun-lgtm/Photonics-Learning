双光梳的异步采样与射频-光频映射表征
物理图像

在第 8 章（FTIR 光谱仪）中，迈克尔逊干涉仪依赖机械动镜平移扫描两臂相对延时 $\tau$；而第 10 章揭示了锁模脉冲序列本质上是等间距光学频率梳。双光梳光谱技术（Dual-Comb Spectroscopy, DCS）将两把重复频率存在微小差异（$f_{r,1} = f_r$、$f_{r,2} = f_r + \Delta f_r$，$\Delta f_r \ll f_r$）且载波包络偏移频率差为 $\Delta f_{\text{ceo}} = f_{\text{ceo},2} - f_{\text{ceo},1}$ 的相干光梳合束至单点高速光电探测器，在彻底去除机械运动部件的同时，实现微秒至毫秒级高分辨宽带分子光谱测量。

  • 时域视角 — 异步光学采样（ASOPS）：两列脉冲序列构成光学“游标卡尺”。每经过一个脉冲周期 $T_r = 1/f_r$，两脉冲相对延时自动递增 $\Delta\tau = \Delta f_r / f_r^2$，并在 $T_{\text{update}} = 1/\Delta f_r$ 周期内完成一次全扫描，时间轴被线性拉伸 $M = f_r / \Delta f_r \sim 10^4\text{--}10^6$ 倍。
  • 频域视角 — 射频-光频映射图（$0 \sim f_r$，$f_r/2$ 为中分界）：将梳齿捉对拍频产生的射频频率（纵轴 $0 \sim f_r$）对光频 $\nu$ 或梳齿序数 $N$（横轴）作图，即可完整表征双光梳的工作状态。每对相邻梳齿同时给出正向主分支 $f_+(N)$ 与关于中分界线 $f_r/2$ 对称的镜像分支 $f_-(N) = f_r - f_+(N)$。调节光谱带宽 $\Delta\nu_{\text{opt}}$、重频差 $\Delta f_r$、重复频率 $f_r$ 以及载波包络偏移差 $\Delta f_{\text{ceo}}$，会分别改变有效光谱段在映射图上的横向跨度、直线斜率、纵轴高度与垂直截距。只要有效光谱对应的射频范围完全落在中分界线下方 $(0, f_r/2)$ 或完全落在中分界线上方 $(f_r/2, f_r)$（不跨越 $0$、$f_r/2$、$f_r$ 任何一条边界），正负分支互不交叉重叠，即为无混叠有效双光梳系统。

实验物理
  • 色散式探测（非对称构型，Dispersive / Asymmetric DCS）：仅探测光梳（Comb 1）穿过气体样品池，本振梳（Comb 2）作为参考直接合束。探测器外差信号直接线性正比于分子气体的复振幅传递函数 $H(\tilde{\nu}) = \exp\!\left[-\frac{1}{2}\alpha(\tilde{\nu})L + i\Delta\phi(\tilde{\nu})\right]$。经傅里叶变换可同时反演出 Voigt 吸收谱 $\alpha(\tilde{\nu})L$ 与严格满足 Kramers-Kronig 关系的 S 形折射率色散曲线 $\Delta\phi(\tilde{\nu})$；在时域上，因果响应表现为仅出现在中心爆峰单侧（$t > 0$）的分子自由感应衰减（FID）振荡拖尾。
  • 强度式探测（对称构型，Intensity / Symmetric DCS）：两把光梳先合束再共同穿过同一气体样品池（或长程大气开放路径）。两路光经历完全相同的分子折射率相移 $\Delta\phi(\tilde{\nu})$，外差拍频时色散相位严格抵消，仅保留实数功率透射率 $|H(\tilde{\nu})|^2 = \exp[-\alpha(\tilde{\nu})L]$。时域干涉图呈严格偶对称，虽不输出色散相位，但对开放光路大气湍流引起的共模相位抖动具有极强抗干扰能力。
  • HITRAN 标准格式分子吸收数据库：高分辨率透射分子吸收数据库（HITRAN）以标准 160 字符固定列宽格式（.par）收录了大气及痕量分子的精确振转跃迁参数（中心波数 $\tilde{\nu}_{ij}$、296 K 线强 $S_{ij}$、空气/自展宽半宽 $\gamma_{\text{air}}/\gamma_{\text{self}}$、低态能量 $E''$、温度指数 $n_{\text{air}}$ 与压致频移 $\delta_{\text{air}}$）。本章内置近红外波段最具代表性的三种气体：$^{12}\text{C}_2\text{H}_2$（乙炔 $\nu_1+\nu_3$ 带，1530 nm，3:1 核自旋奇偶强弱交替）、$^{12}\text{CO}_2$（二氧化碳 $30012\leftarrow 00001$ 带，1575 nm，仅存偶 $J$ 谱线与 R 支带头）与$^{12}\text{CH}_4$（甲烷 $2\nu_3$ 泛频带，1666 nm，尖锐 Q 支簇与 $A/E/F$ 多重分裂）。
1双光梳时域异步采样（ASOPS）与拉伸因子推导
两列周期脉冲序列的相对走离与等效延迟轴
时域推导

设两把相干光学频率梳的脉冲重复周期分别为 $T_{r,1} = 1/f_r$ 与 $T_{r,2} = 1/(f_r + \Delta f_r)$（$0 < \Delta f_r \ll f_r$）。每经过一个脉冲周期，两列脉冲相对延时自动步进 $\Delta\tau$，时间拉伸（频率压缩）因子 $M$ 与单次干涉图刷新周期 $T_{\text{update}}$ 为：

$$\Delta\tau = T_{r,1} - T_{r,2} = \frac{\Delta f_r}{f_r(f_r + \Delta f_r)} \approx \frac{\Delta f_r}{f_r^2}, \qquad M \equiv \frac{f_r}{\Delta f_r}, \qquad \tau_{\text{eff}}(t) = \frac{t}{M}, \qquad T_{\text{update}} = \frac{1}{\Delta f_r}$$
飞秒级等效光延迟被线性拉伸 $M$ 倍至微秒/毫秒级实验室时间轴
2射频-光频映射方程与双区间无重叠判据
主拍频分支、镜像分支与中分界 $f_r/2$ 无混叠充要条件
映射理论

由第 10 章频率梳方程，两把光梳第 $n$ 根梳齿的光学频率为 $\nu_{1,n} = f_{\text{ceo},1} + n f_r$ 与 $\nu_{2,n} = f_{\text{ceo},2} + n(f_r + \Delta f_r)$。以光谱中心频率 $\nu_0$ 对应的中心齿 $n_0$ 为参考，定义相对梳齿序数 $\Delta N = n - n_0 = (\nu - \nu_0)/f_r$，并将中心齿的初始外差频偏记为 $\Delta f_{\text{ceo,eff}} \equiv (f_{\text{ceo},2} - f_{\text{ceo},1} + n_0\Delta f_r) \bmod f_r \in [0, f_r)$。

梳齿捉对拍频在射频区间 $[0, f_r]$ 内形成两条关于中分界线 $f_r/2$ 严格对称的映射斜线：

$$f_{\text{raw}}(\Delta N) = \Delta f_{\text{ceo,eff}} + \Delta N\,\Delta f_r = \Delta f_{\text{ceo,eff}} + \frac{\Delta f_r}{f_r}(\nu - \nu_0)$$ $$f_+(\Delta N) = f_{\text{raw}}(\Delta N) \bmod f_r \in [0, f_r), \qquad f_-(\Delta N) = f_r - f_+(\Delta N) \in (0, f_r]$$
主分支 $f_+$（同阶齿拍频）与镜像分支 $f_-$（相邻阶齿拍频）关于中分界 $f_r/2$ 上下对称

设有效光梳光谱覆盖 $[\nu_0 - \Delta\nu_{\text{opt}}/2,\; \nu_0 + \Delta\nu_{\text{opt}}/2]$，对应的射频跨度为 $\Delta f_{\text{RF}} = \Delta\nu_{\text{opt}}\cdot\frac{\Delta f_r}{f_r}$，上下端点为 $f_{\text{low}} = \Delta f_{\text{ceo,eff}} - \frac{1}{2}\Delta f_{\text{RF}}$ 与 $f_{\text{high}} = \Delta f_{\text{ceo,eff}} + \frac{1}{2}\Delta f_{\text{RF}}$。系统无混叠有效的充要条件是整段 $[f_{\text{low}}, f_{\text{high}}]$ 完全落于中分界下方或上方：

$$\underbrace{0 < f_{\text{low}} < f_{\text{high}} < \frac{f_r}{2}}_{\text{下半区有效（正向一对一映射）}} \qquad \text{或} \qquad \underbrace{\frac{f_r}{2} < f_{\text{low}} < f_{\text{high}} < f_r}_{\text{上半区有效（镜像反转一对一映射）}}$$ $$\Longrightarrow \quad \text{最大无混叠光带宽：}\;\Delta\nu_{\text{opt,max}} = \frac{f_r^2}{2\,\Delta f_r}$$
不仅要求 $\Delta\nu_{\text{opt}} < \Delta\nu_{\text{opt,max}}$，还要求 $\Delta f_{\text{ceo,eff}}$ 避开 $0$、$f_r/2$ 与 $f_r$ 三条边界线

当有效射频段落于上半区 $(f_r/2, f_r)$ 时，实光电信号将其无重叠地镜像折叠至探测器频带 $f_{\text{det}} = f_r - f_{\text{raw}} \in (0, f_r/2)$，只需按逆序解映射并取复共轭即可无损还原真实复光谱；一旦跨过 $f_r/2$ 或 $0/f_r$，则两段光学光谱在射频域重叠产生不可分离的混叠伪峰。

3HITRAN 标准复 Voigt 吸收-色散模型与信噪比
HITRAN 谱线参数、复 Faddeeva 函数与色散/强度双探测反演
HITRAN 建模

从标准 HITRAN 160-字符 .par 记录中读取第 $j$ 条分子跃迁的真空波数 $\tilde{\nu}_{0,j}$（$\text{cm}^{-1}$）、参考温度 $T_{\text{ref}} = 296\,\text{K}$ 下的线强 $S_{j}(T_{\text{ref}})$（$\text{cm}^{-1}/(\text{molecule}\cdot\text{cm}^{-2})$）、空气/自展宽系数 $\gamma_{\text{air},j}, \gamma_{\text{self},j}$、低态能量 $E''_j$、温度指数 $n_{\text{air},j}$ 与压致频移 $\delta_{\text{air},j}$。在总压强 $p$（atm）、体积摩尔分数 $\chi$、温度 $T$（K）下：

$$S_j(T) = S_j(T_{\text{ref}})\frac{Q(T_{\text{ref}})}{Q(T)}\exp\!\left[-c_2 E''_j\left(\frac{1}{T} - \frac{1}{T_{\text{ref}}}\right)\right], \qquad \tilde{\nu}_j^* = \tilde{\nu}_{0,j} + \delta_{\text{air},j}\,p$$ $$\gamma_{L,j}(p, T) = \left(\frac{T_{\text{ref}}}{T}\right)^{n_{\text{air},j}}\big[\gamma_{\text{air},j}(1-\chi) + \gamma_{\text{self},j}\chi\big]p, \qquad \gamma_{D,j}(T) = \frac{\tilde{\nu}_{0,j}}{c}\sqrt{\frac{2 k_B T \ln 2}{m}}$$

引入复 Faddeeva 函数 $w(z) = e^{-z^2}\operatorname{erfc}(-iz)$（其中 $x_j = \frac{\sqrt{\ln 2}}{\gamma_{D,j}}(\tilde{\nu} - \tilde{\nu}_j^*)$，$y_j = \frac{\sqrt{\ln 2}\,\gamma_{L,j}}{\gamma_{D,j}}$），其实部给出归一化 Voigt 吸收线型，虚部严格给出满足 Kramers-Kronig 关系的 Voigt 色散相位线型：

$$H(\tilde{\nu}) = \exp\!\left[-\frac{\alpha(\tilde{\nu})L}{2} + i\,\Delta\phi(\tilde{\nu})\right], \qquad \alpha(\tilde{\nu})L = n_{\text{mol}} L \sum_j S_j(T)\frac{\sqrt{\ln 2/\pi}}{\gamma_{D,j}}\operatorname{Re}\!\big[w(x_j + i y_j)\big]$$ $$\Delta\phi(\tilde{\nu}) = -\frac{1}{2}\,n_{\text{mol}} L \sum_j S_j(T)\frac{\sqrt{\ln 2/\pi}}{\gamma_{D,j}}\operatorname{Im}\!\big[w(x_j + i y_j)\big]$$
$n_{\text{mol}} = \chi p N_L (T_{\text{ref}}/T)$ 为吸收分子数密度（$\text{molecule}/\text{cm}^3$）
  • 色散式探测（非对称构型）：测得复外差光谱比 $\tilde{S}_{\text{meas}}/\tilde{S}_0 = H(\tilde{\nu})$，同步提取 $\alpha_{\text{meas}} L = -2\ln|\tilde{S}_{\text{meas}}/\tilde{S}_0|$ 与 $\Delta\phi_{\text{meas}} = \arg(\tilde{S}_{\text{meas}}/\tilde{S}_0)$。
  • 强度式探测（对称构型）：测得 $\tilde{S}_{\text{meas}}/\tilde{S}_0 = |H(\tilde{\nu})|^2 = e^{-\alpha(\tilde{\nu})L}$，提取 $\alpha_{\text{meas}} L = -\ln|\tilde{S}_{\text{meas}}/\tilde{S}_0|$，色散相位 $\Delta\phi_{\text{meas}} \equiv 0$。

相干平均与探测信噪比：对 $N_{\text{avg}}$ 帧连续干涉图相干平均，有效噪声按 $1/\sqrt{N_{\text{avg}}}$ 衰减，信噪比提升为 $\text{SNR}(N_{\text{avg}}) = \text{SNR}_1 \cdot \sqrt{N_{\text{avg}}} \cdot e^{-\sigma_\phi^2/2}$。

数值仿真算法：HITRAN `.par` 解析 + Weideman 16 阶复 Voigt + 4096 点 FFT
数值算法
  1. 标准 HITRAN `.par` 列宽解析：仿真引擎直接解析内置的 HITRAN 固定列宽字符串，提取 $\tilde{\nu}_{0,j}, S_j, \gamma_{\text{air},j}, \gamma_{\text{self},j}, E''_j, n_{\text{air},j}, \delta_{\text{air},j}$ 并按气室压强 $p$ 与光程 $L$ 实时合成复透射谱。
  2. Weideman $N=16$ 复 Faddeeva 逼近：在复上半平面用 16 阶有理多项式计算 $w(x+iy)$（相对误差 $< 8\times 10^{-8}$），同步获得无近似失真的 Voigt 吸收与 Kramers-Kronig 色散相位。
  3. 双区精确折叠与解映射（$N=4096$）：对超高斯带通光梳执行逐频点映射 $f_{\text{raw}} = \Delta f_{\text{ceo,eff}} + (\nu-\nu_0)\frac{\Delta f_r}{f_r}$ 并折叠入 $[0, f_r/2]$（奇数折叠区显式施加复共轭），经 IFFT 合成含因果 FID 尾的时域干涉图、注入按 $1/\sqrt{N_{\text{avg}}}$ 缩放的高斯探测白噪声，再经 FFT 依据中心工作区（下半区正向 / 上半区共轭反转）反演分子吸收与色散光谱。
