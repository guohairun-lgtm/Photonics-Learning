2二阶三类过程、各向同性三阶与四阶色散双边色散波
一、单脉冲二阶效应（仅 $d_{33}$ 主轴极化）的三重物理内涵
二阶 $d_{33}$

当单脉冲沿单轴/双轴铁电晶体光轴偏振（如周期极化薄膜铌酸锂 PPLN 中的 $e + e \to e$ 准相位匹配，利用最大非线性系数 $d_{33} \approx 27\,\text{pm/V}$）传输时，二阶非线性极化张量退化为单一对角分量 $\chi^{(2)}_{333} = 2d_{33}$，可用单一标量极化公式统一描述以下三类物理过程：

  1. 倍频过程（SHG, $\omega_0 + \omega_0 \to 2\omega_0$）：当周期极化光栅波矢 $K_m = 2\pi m/\Lambda$ 补偿色散波矢失配，使 $\Delta k_{\text{eff}} = \beta(2\omega_0) - 2\beta(\omega_0) - K_m \approx 0$ 时，基频能量在相干长度 $L_c \to \infty$ 内持续单向转换为二次谐波 $A_2$（由开关 $\sigma_{\text{SHG}}$ 控制）。
  2. 可调级联二阶等效三阶过程（Cascaded $\chi^{(2)}$）：当系统处于大相位失配区（$|\Delta k_{\text{eff}}| L \gg 1$）时，基频光在每个相干长度 $L_c$ 内反复经历“上转换 $\omega_0 + \omega_0 \to 2\omega_0$”与“下转换 $2\omega_0 - \omega_0 \to \omega_0$”的循环，回流能量附加正比于 $|A_1|^2$ 的非线性相移，等效于人为设计的 Kerr 非线性系数 $\gamma_{\text{casc}} = -\frac{\kappa_2^2}{\Delta k_{\text{eff}}}$：
    • 正失配区（$\Delta k_{\text{eff}} > 0$）：产生负等效 Kerr 非线性（$\gamma_{\text{casc}} < 0$，自散焦），可抵消介质本征正 Kerr 效应，甚至可在正常色散区（$\beta_2 > 0$）支持亮孤子自压缩。
    • 负失配区（$\Delta k_{\text{eff}} < 0$）：产生正等效 Kerr 非线性（$\gamma_{\text{casc}} > 0$，自聚焦），即便关闭介质本征三阶非线性（$\chi^{(3)} = 0$），仅靠纯级联二阶效应即可驱动孤子自压缩与频谱展宽。
  3. 脉冲内自差频（IDFG / Optical Rectification, $\omega_1 - \omega_2 \to \Omega_{\text{IR}}$）：宽带超短单脉冲内部的高频光谱成分 $\omega_1$ 与低频光谱成分 $\omega_2$ 通过 $d_{33}$ 的 $|\mathcal{E}|^2$ 项发生差频混频，无需外部种子光即可直接辐射出中红外（MIR）或太赫兹（THz）脉冲 $A_{\text{IR}}$。当基频脉冲经历孤子自压缩或脉宽变窄时，光强包络 $|A_1|^2$ 频谱显著拓宽，自差频红外转换效率急剧提升。
二、各向同性三阶效应（$\chi^{(3)}$）：四阶色散双边色散波与三倍频 THG
各向同性 $\chi^{(3)}$

在各向同性介质（如石英光子晶体光纤、非晶 $\text{Si}_3\text{N}_4$ 集成波导）中，空间反演对称性使 $\chi^{(2)} \equiv 0$，三阶极化率张量仅有唯一独立分量 $\chi^{(3)}_{xxxx} = 3\chi^{(3)}_{xxyy}$。单偏振脉冲在该标量 $\chi^{(3)}_{xxxx}$ 作用下同步发生两类非线性过程：

  • SPM 孤子裂变与四阶色散双边色散波（Bilateral Dispersive Waves, $\beta_2 < 0, \beta_4 > 0$）：当波导色散工程在泵浦频率附近呈现反常色散（$\beta_2 < 0$）且具有正四阶色散（$\beta_4 > 0$）时，局域群速度色散 $\beta_2^{\text{eff}}(\Omega) = \beta_2 + \beta_3\Omega + \frac{\beta_4}{2}\Omega^2$ 在泵浦两侧分别穿过零点，形成双零色散频率（$\Omega_{\text{ZDW},-} < 0$ 与 $\Omega_{\text{ZDW},+} > 0$）。高阶孤子（$N \ge 2$）在 $L_{\text{fiss}} \approx L_D/N$ 裂变时，积分色散 $\beta_{\text{int}}(\Omega)$ 在高频（蓝移）与低频（红移）两侧同时上翘并与孤子非线性波数 $k_{\text{sol}} = \frac{1}{2}\gamma P_s$ 相交，从而在频谱两端同步辐射出双边切伦科夫色散波（$\Omega_{\text{DW},-}$ 与 $\Omega_{\text{DW},+}$），大幅拓宽倍频程超连续谱。
  • 同步三倍频（THG, $3\omega_0$）：三阶极化中的 $\mathcal{E}^3$ 项直接将三个基频光子合成为三倍频光子（$A_3 \propto \int A_1^3 e^{-i\Delta k_{\text{THG}} z}\mathrm{d}z$），在高阶孤子发生剧烈时域自压缩、峰值功率骤增数倍的瞬间集中爆发。
三、频域非线性色散（自陡峭）、光子数守恒与类 Kramers-Kronig 损耗
深度剖析
  • 自陡峭的频域本质 = 非线性色散 $\gamma(\omega)$：时域自陡峭算子 $\left(1 + \frac{i}{\omega_0}\frac{\partial}{\partial T}\right)$ 在频域严格对应乘以频率因子 $\left(1 + \frac{\Omega}{\omega_0}\right) = \frac{\omega}{\omega_0}$，使非线性系数成为频率的函数 $\gamma(\omega) = \frac{n_2(\omega)\omega}{c A_{\text{eff}}(\omega)}$。
  • 能量不守恒 vs 总光子数守恒（Manley-Rowe 定律）：在无线性与双光子损耗时，非线性参量混频过程严格保持总光子数 $N_{\text{ph}} = \sum_j \int \frac{|\tilde{A}_j(\omega)|^2}{\hbar\omega}\,\mathrm{d}\omega$ 守恒；当自陡峭导致频谱重心漂移时，总能量 $E_{\text{tot}}(z)$ 随之改变。
  • 非线性 Kramers-Kronig（K-K）关系与非线性吸收损耗：非线性折射率色散 $n_2(\omega)$ 与双光子吸收系数 $\beta_{\text{TPA}}(\omega)$ 构成希尔伯特变换对，宽带非线性色散必然伴随虚部非线性吸收损耗 $\tilde{\gamma}(\omega) = \gamma(\omega) + i\frac{\beta_{\text{TPA}}(\omega)}{2A_{\text{eff}}(\omega)}$。

设单脉冲沿非线性晶体光轴偏振（如 PPLN 中的 $e$ 偏振，$z$ 轴主轴方向），仅保留对角非线性分量 $d_{33}$（$\chi^{(2)}_{333} = 2d_{33}$）。令实电场为 $E(z,t) = \frac{1}{2}\big[\mathcal{E}(z,t) + \mathcal{E}^*(z,t)\big]$，二阶非线性极化限定于如下单一标量公式：

$$P^{(2)}(z, t) = \varepsilon_0 \chi^{(2)}_{333}(z)\,E^2(z,t) = \frac{\varepsilon_0 d_{33}(z)}{2}\Big[\underbrace{\sigma_{\text{SHG/casc}}\,\mathcal{E}^2(z,t)}_{\text{倍频 SHG 与级联二阶 } (2\omega_0)} + \underbrace{2\,\sigma_{\text{IDFG}}\,|\mathcal{E}(z,t)|^2}_{\text{脉冲内自差频 IDFG } (\Omega_{\text{IR}} = \omega_1 - \omega_2)} + \text{c.c.}\Big]$$ $$\tilde{P}^{(2)}(z, \omega) = \frac{\varepsilon_0 d_{33}(z)}{\pi}\int_{-\infty}^{+\infty} \tilde{E}(z, \omega')\,\tilde{E}(z, \omega - \omega')\,\mathrm{d}\omega'$$
