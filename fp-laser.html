3F-P 腔激光器

半导体增益介质 + 谐振腔 + 电流注入泵浦：速率方程、阈值条件、稳态光谱与动态行为

F-P 腔激光器基本结构
原理

F-P 腔激光器是在法布里-珀罗谐振腔内放置半导体增益介质，通过电流注入实现粒子数反转，产生受激辐射放大。当腔内增益超过总损耗时，激光振荡建立，形成稳定激光输出。

核心组件：

  • 有源区（增益介质）：半导体异质结（如 InGaAsP/InP），载流子通过电流注入产生粒子数反转，提供光增益 $g(N)$。
  • 前腔镜（输出镜）：具有有限光谱带宽的半反射镜，反射率 $R_2$，带宽 $\Delta\nu_m$。
  • 后腔镜（全反射镜）：反射率 $R_1 \approx 1$，无带宽限制。
  • 泵浦源：电流注入 $I$，产生载流子浓度 $N$，驱动增益。

载流子-光子速率方程与第二章的联系
贯通

载流子-光子速率方程是描述半导体激光器动态行为的核心模型。载流子浓度 $N$ 和光子密度 $S$ 的耦合演化：

  • 载流子方程：电流注入产生载流子，通过受激辐射复合（产生光子）、自发辐射和非辐射复合消耗。
  • 光子方程：受激辐射产生光子，腔损耗（镜面输出 + 内部损耗）消耗光子。
  • 增益函数：线性模型 $g(N) = a(N - N_{\text{tr}})$，$N_{\text{tr}}$ 为透明载流子浓度。
  • 阈值条件：增益 = 腔总损耗（镜面损耗 + 内部损耗），对应阈值电流 $I_{\text{th}}$。

与第二章 GLE 的关系：光子速率方程是 GLE 在单模近似、取强度后的简化形式。GLE 描述光场复振幅（含相位、频谱），速率方程描述光子密度（仅强度）。GLE 中的常数增益 $g_{\text{pk}}$ 在速率方程中被溯源到载流子动力学 $g(N)$，使系统从单变量扩展到双变量耦合，能描述弛豫振荡、载流子钳制等现象。

线宽特征：激光线宽物理来源是自发辐射噪声对相位的随机扰动。Schawlow-Townes 公式给出基本线宽，Henry 线宽增强因子 $\alpha_H$ 使实际线宽增大 $(1+\alpha_H^2)$ 倍。关键影响因素：输出功率（$\Delta\nu \propto 1/P$）、腔长（增大光子寿命）、微分增益、$\alpha_H$、温度。

载流子-光子速率方程
推导

载流子速率方程（电流注入 → 载流子 → 增益）：

$$\frac{dN}{dt} = \frac{\eta_i I}{q V} - \frac{N}{\tau_n} - v_g g(N) S$$
$\eta_i$ 注入效率，$V$ 有源区体积，$\tau_n$ 载流子寿命，$v_g$ 群速度

光子速率方程（光场建立 → 稳态激光）：

$$\frac{dS}{dt} = \Gamma v_g g(N) S - \frac{S}{\tau_p} + \beta \frac{N}{\tau_n}$$
$\Gamma$ 光场限制因子，$\tau_p$ 光子寿命，$\beta$ 自发辐射耦合因子

线性增益模型：

$$g(N) = a(N - N_{\text{tr}})$$
$a$ 微分增益，$N_{\text{tr}}$ 透明载流子浓度
阈值条件与稳态功率
参数

腔总损耗（镜面损耗 + 内部损耗）：

$$\alpha_{\text{tot}} = \alpha_{\text{int}} + \frac{1}{2L}\ln\frac{1}{R_1 R_2}$$

光子寿命与阈值增益：

$$\tau_p = \frac{1}{v_g \alpha_{\text{tot}}}, \quad g_{\text{th}} = \frac{\alpha_{\text{tot}}}{\Gamma}$$

阈值电流：

$$I_{\text{th}} = \frac{qV}{\eta_i \tau_n}\left(N_{\text{tr}} + \frac{g_{\text{th}}}{a}\right)$$
阈值条件：增益 = 总损耗

稳态输出功率：

$$P_{\text{out}} = \eta_d \frac{h\nu}{q}(I - I_{\text{th}})$$
$\eta_d$ 微分量子效率

输出镜光谱带宽（高斯型）：

$$T_2(\nu) = T_{\text{peak}} \exp\!\left[-\left(\frac{\nu - \nu_0}{\Delta\nu_m/2}\right)^2 \ln 2\right]$$
归一化速率方程与稳态解
归一化

定义归一化变量（透明密度忽略极限下以阈值密度为基准）：$\tilde{N} = N/N_{\text{th}}$，$\tilde{S} = S/S_0$，$\tilde{t} = t/\tau_n$，$J = I/I_{\text{th}}$，$\gamma = \tau_n/\tau_p$：

$$\frac{d\tilde{N}}{d\tilde{t}} = J - \tilde{N} - \tilde{N}\tilde{S}$$
归一化载流子速率方程
$$\frac{d\tilde{S}}{d\tilde{t}} = \gamma\left[(\tilde{N} - 1)\tilde{S} + \beta\tilde{N}\right]$$
归一化光子速率方程，$\gamma = \tau_n/\tau_p$

稳态解（$J > 1$，$\beta \ll 1$）：

$$\tilde{N}_{\text{ss}} \approx 1, \qquad \tilde{S}_{\text{ss}} \approx J - 1, \qquad \omega_R = \sqrt{\gamma(J - 1)}$$
载流子钳制在阈值，光子正比于泵浦，弛豫振荡频率 $f_R = \frac{1}{2\pi}\sqrt{\gamma(J-1)}$

稳态激光光谱：

$$P(\nu) \propto \frac{\tilde{S}_{\text{ss}} \cdot T_2(\nu)}{1 + F\sin^2(\delta/2)} \cdot \exp\!\left[-4\ln 2\left(\frac{\nu - \nu_0}{\Delta\nu_g}\right)^2\right]$$
激光输出谱 = 腔模式（Airy）× 输出镜透过率 × 增益包络
激光线宽公式
线宽

Schawlow-Townes 基本线宽：

$$\Delta\nu_{\text{ST}} = \frac{v_g^2 h\nu g_{\text{th}} n_{\text{sp}} \alpha_m}{8\pi P_{\text{out}}}$$

含 Henry 增强的实际线宽：

$$\Delta\nu = \Delta\nu_{\text{ST}}(1 + \alpha_H^2), \quad \alpha_H = \frac{\partial n'/\partial N}{\partial n''/\partial N}$$
$\alpha_H$ 线宽增强因子（Henry factor），典型值 2–7

归一化线宽：

$$\Delta\nu_L = \frac{\gamma\beta}{4\pi\tilde{S}_{\text{ss}}}(1 + \alpha_H^2)$$
归一化 Schawlow-Townes-Henry 线宽
仿真算法：刚性速率方程的自适应子步 RK4 求解
数值算法

由于半导体激光器中 $\gamma = \tau_n/\tau_p \sim 10^2\text{--}3\times 10^3$，系统呈强刚性，固定步长容易在 $\gamma$ 较大时发散。仿真器采用经典四阶龙格-库塔法（RK4），每帧动态选取子步长 $\Delta\tilde{t} \le \min\left(10^{-3},\; \frac{0.05}{\gamma}\right)$，保证高 $\gamma$ 下弛豫振荡波形精确稳定。
