10脉冲式激光的时频域关系

周期脉冲序列与光学频率梳 → $\beta$-$\omega$ 空间中的群速度、相速度与 $f_{\text{ceo}}$ 几何起源 → 啁啾脉冲序列的频率梳不变性 → 谐振腔纵模色散的统一图像

1周期脉冲激光与光学频率梳的本质等价
时域周期脉冲序列 ↔ 频域等间距频率梳
核心概念

在锁模激光器（第 7 章）或微腔耗散孤子（第 6 章）中，激光脉冲在谐振腔内周期性往返，每经过一个往返周期 $T_R = 1/f_{\text{rep}}$ 便向腔外输出一个超短脉冲。从傅里叶分析的视角看，时域的严格周期性必然对应频域的离散梳状结构——任何稳定的周期脉冲激光，其频谱本质上就是一把光学频率梳（Optical Frequency Comb）。

  • 梳齿间距 $f_{\text{rep}}$：由脉冲序列的重复频率 $f_{\text{rep}} = 1/T_R$ 决定，相邻梳齿频率严格等间隔。
  • 频谱包络：由单个脉冲的时域波形（脉宽 $\tau_p$ 与形态）通过傅里叶变换决定；脉冲越短，频率梳覆盖的光谱带宽越宽。
  • 载波包络偏移频率 $f_{\text{ceo}}$：脉冲包络以群速度 $v_g$ 传播，而内部光载波以相速度 $v_p$ 传播；两者之差导致相邻脉冲间的载波相位相对包络中心发生固定滑移 $\Delta\phi_{\text{ce}}$，在频域表现为整把频率梳相对于频率零点（$f=0$）的整体平移 $f_{\text{ceo}} = \frac{\Delta\phi_{\text{ce}}}{2\pi} f_{\text{rep}}$。
2$\beta$-$\omega$ 空间中的几何统一图像
锁模直线、群速度、相速度与 $f_{\text{ceo}}$ 的几何起源
几何直觉

将光场的传播常数 $\beta$（空间角频率）与角频率 $\omega$ 绘制在二维 $\beta$-$\omega$ 空间中，可以把脉冲锁模、色散效应、载波包络偏移以及冷腔谐振模式统一在同一幅几何图像下：

图 1. $\beta$-$\omega$ 空间中的频率梳几何图像：切线斜率 $v_g$、原点割线斜率 $v_p$、纵轴截距 $\omega_{\text{ceo}}$ 与冷腔反函数色散曲线 $\omega(\beta)$
  • 锁模状态 = $\beta$-$\omega$ 空间中的一条斜直线：锁模要求所有频率分量以完全相同的群速度 $v_g$ 共同前进（无脉冲走离），因此频率梳各模式点 $(\beta_m, \omega_m)$ 严格落在过中心点 $(\beta_0, \omega_0)$、斜率为 $v_g = \left.\frac{\mathrm{d}\omega}{\mathrm{d}\beta}\right|_{\omega_0} = \left(\left.\frac{\mathrm{d}\beta}{\mathrm{d}\omega}\right|_{\omega_0}\right)^{-1}$ 的直线上。
  • 相速度与 $f_{\text{ceo}}$ 的必然性：原点 $(0,0)$ 到中心点 $(\beta_0, \omega_0)$ 连线的斜率定义了相速度 $v_p = \omega_0/\beta_0$。在真空中 $v_g = v_p = c$，锁模直线严格过原点（$f_{\text{ceo}} = 0$）；而在光纤、晶体或氮化硅微腔等色散介质中 $v_g \neq v_p$，锁模直线反向延长至 $\beta = 0$ 处必然产生非零纵轴截距，这正是不同脉冲激光系统中普遍存在载波包络偏移频率 $f_{\text{ceo}}$ 的根本物理原因。
3啁啾脉冲序列与谐振腔模式的统一理解
啁啾脉冲序列的频率梳不变性
推广

若周期脉冲序列经过一段色散介质或本身处于强啁啾锁模态（如第 7 章正常色散平顶脉冲 DSR），各频率分量之间不再满足“零相位差”，而是带有随频率变化的静态光谱相位 $\phi(\omega) = \frac{1}{2}\phi_2(\omega-\omega_0)^2 + \cdots$。此时：

  • 频率梳结构依然严格存在：只要每个脉冲携带相同的光谱相位且重复周期恒为 $T_R$，频域上依然是等间距的离散频率梳，梳齿频率位置 $f_m = f_{\text{ceo}} + m f_{\text{rep}}$ 完全不变，改变的仅是各根梳齿的相对初相位。
  • 中心频率处的 $v_g$ 与 $v_p$ 依然明确定义：仍可由色散曲线在中心频率 $\omega_0$ 处的一阶导数 $\beta_1 = \left.\frac{\mathrm{d}\beta}{\mathrm{d}\omega}\right|_{\omega_0} = 1/v_g$ 定义脉冲包络的群速度，由 $\beta(\omega_0)/\omega_0 = 1/v_p$ 定义载波相速度，而二阶导数 $\beta_2 = \left.\frac{\mathrm{d}^2\beta}{\mathrm{d}\omega^2}\right|_{\omega_0}$ 则描述脉冲在传播中的啁啾展宽。
$\beta$-$\omega$ 反函数与谐振腔纵模体系的统一
全书贯通

在光学谐振腔（第 1 章 F-P 腔、第 6 章高 $Q$ 微环腔）中，驻波或周期性边界条件将传播常数离散化为等间距网格 $\beta_m = \frac{2\pi}{L} m$。此时，$\beta(\omega)$ 的反函数 $\omega(\beta)$ 直接给出了冷腔第 $m$ 阶纵模的谐振频率 $\omega_m = \omega(\beta_m)$：

  • 冷腔（线性）纵模：受材料与波导色散影响，$\omega(\beta)$ 是一条弯曲曲线，相邻纵模间距（局域 FSR）随频率变化，偏离等间距直线的量即为积分色散 $D_{\text{int}}(\mu)$。
  • 锁模 / 孤子（非线性）频率梳：在 Kerr 非线性、四波混频或可饱和吸收的锁模作用下，原本弯曲的冷腔纵模被非线性相移“拉直”到斜率为 $v_g$ 的严格直线上，从而在时域凝聚为不失真传播的周期超短脉冲。
1周期脉冲序列的傅里叶变换与频率梳方程
含载波包络相位滑移 $\Delta\phi_{\text{ce}}$ 的周期脉冲序列
推导

设单个超快脉冲的复慢变包络为 $A(t)$（可含任意啁啾相位），中心角频率为 $\omega_0 = 2\pi f_0$。重复周期为 $T_R = 1/f_{\text{rep}}$、相邻脉冲间载波包络相位滑移为 $\Delta\phi_{\text{ce}}$ 的无限脉冲序列可写为：

$$E_{\text{train}}(t) = \sum_{n=-\infty}^{+\infty} A(t - n T_R)\,\exp\!\left[i\omega_0(t - n T_R) + i\left(\phi_0 + n\,\Delta\phi_{\text{ce}}\right)\right]$$
第 $n$ 个脉冲包络位于 $n T_R$，其载波相对包络的初相位递增 $n\,\Delta\phi_{\text{ce}}$

对其执行傅里叶变换 $\tilde{E}_{\text{train}}(\omega) = \int_{-\infty}^{+\infty} E_{\text{train}}(t)e^{-i\omega t}\,\mathrm{d}t$，作变量替换 $t' = t - n T_R$ 并利用泊松求和公式 $\sum_{n} e^{in(\Delta\phi_{\text{ce}} - \omega T_R)} = \frac{2\pi}{T_R}\sum_{m}\delta\!\left(\omega - \frac{\Delta\phi_{\text{ce}}}{T_R} - m\frac{2\pi}{T_R}\right)$：

$$\tilde{E}_{\text{train}}(\omega) = e^{i\phi_0}\,\tilde{A}(\omega - \omega_0) \cdot \frac{2\pi}{T_R}\sum_{m=-\infty}^{+\infty} \delta\!\left(\omega - \omega_{\text{ceo}} - m\,\omega_{\text{rep}}\right)$$
频率梳核心公式：$f_m = f_{\text{ceo}} + m\,f_{\text{rep}}$，其中 $f_{\text{rep}} = \frac{1}{T_R}$，$f_{\text{ceo}} = \frac{\Delta\phi_{\text{ce}}}{2\pi} f_{\text{rep}}$

啁啾脉冲序列推广：若单脉冲包络在频域带有色散相位 $\tilde{A}(\omega - \omega_0) = |\tilde{A}(\omega - \omega_0)|\,e^{i\phi_{\text{disp}}(\omega)}$，代入上式仅在每根梳齿上乘以复因子 $e^{i\phi_{\text{disp}}(\omega_m)}$，狄拉克梳 $\delta(\omega - \omega_{\text{ceo}} - m\omega_{\text{rep}})$ 的位置完全不变。

2$\beta$-$\omega$ 空间的群速度、相速度与 $f_{\text{ceo}}$ 关系
色散展开与纵轴截距公式
色散关系

将介质或波导的传播常数 $\beta(\omega)$ 在中心频率 $\omega_0$ 处做泰勒展开：

$$\beta(\omega) = \beta_0 + \beta_1(\omega - \omega_0) + \frac{1}{2}\beta_2(\omega - \omega_0)^2 + \frac{1}{6}\beta_3(\omega - \omega_0)^3 + \cdots$$
相速度 $v_p = \dfrac{\omega_0}{\beta_0} = \dfrac{c}{n(\omega_0)}$，群速度 $v_g = \left(\left.\dfrac{\mathrm{d}\beta}{\mathrm{d}\omega}\right|_{\omega_0}\right)^{-1} = \dfrac{1}{\beta_1} = \dfrac{c}{n_g(\omega_0)}$

在锁模状态下，脉冲沿长度 $L$ 的腔体往返一周所需时间为 $T_R = L/v_g = \beta_1 L$，而中心载波在一周内积累的相位差（载波相位减去包络位置对应的传播相位）为：

$$\Delta\phi_{\text{ce}} = \omega_0 T_R - \beta_0 L = \omega_0 L \left(\frac{1}{v_g} - \frac{1}{v_p}\right) \pmod{2\pi}$$
群速度与相速度之差直接决定了脉冲间的载波包络相位滑移

在 $(\beta, \omega)$ 平面中，过 $(\beta_0, \omega_0)$、斜率为 $v_g$ 的锁模直线方程为 $\omega(\beta) = \omega_0 + v_g(\beta - \beta_0)$。令 $\beta = 0$ 得纵轴截距：

$$\omega_{\text{offset}} = \omega_0 - v_g \beta_0 = \omega_0 \left(1 - \frac{v_g}{v_p}\right), \qquad \omega_{\text{ceo}} = \omega_{\text{offset}} \pmod{\omega_{\text{rep}}}$$
当且仅当 $v_g = v_p$（无色散）时直线过原点，$\omega_{\text{ceo}} = 0$
3$\beta$-$\omega$ 反函数与谐振腔模式色散
冷腔谐振频率 $\omega_\mu$ 与积分色散 $D_{\text{int}}(\mu)$
谐振腔统一

对光学长度（几何周长）为 $L$ 的环形微腔或 F-P 腔（单程 $L/2$），纵模驻波条件为 $\beta(\omega_m) L = 2\pi m$，即 $\beta_m = \frac{2\pi}{L} m$。将 $\beta(\omega)$ 反解为 $\omega(\beta)$ 并在参考模 $m_0$（相对模序 $\mu = m - m_0$）附近展开：

$$\omega_\mu = \omega(\beta_{m_0 + \mu}) = \omega_0 + D_1 \mu + \frac{1}{2} D_2 \mu^2 + \frac{1}{6} D_3 \mu^3 + \cdots$$
反函数一阶导数给出自由光谱范围 $D_1 = \frac{2\pi v_g}{L} = 2\pi\,\text{FSR}$，二阶导数给出色散项 $D_2 = -\frac{c}{n_g} D_1^2 \beta_2$

定义冷腔模式相对于等间距锁模直线的偏离为积分色散：

$$D_{\text{int}}(\mu) \equiv \omega_\mu - (\omega_0 + D_1 \mu) = \frac{1}{2} D_2 \mu^2 + \frac{1}{6} D_3 \mu^3 + \cdots$$
当微腔中形成 Kerr 耗散孤子（第 6 章）或锁模孤子（第 7 章）时，非线性相移与失谐抵消 $D_{\text{int}}(\mu)$，使全部梳齿锁在 $D_{\text{int}}=0$ 的直线上
